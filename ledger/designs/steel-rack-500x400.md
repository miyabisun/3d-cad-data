# スチールラック 500x400

## 目的

既製品のサーバーラックは高価なため、強度の必要な箇所はホームセンターで
買える汎用材（L字アングル等）で実装し、安くスチールラックを組み上げる。
特定の製品（メーカー・型番）に対応するものではない。

## 現行構成

- 縦柱: ホームセンターで見かけたL字アングル 600mm ×4本を縦に配置
- 天板: はざいや（アクリル板を加工・納品してくれるサイト）に発注した
  500x400 のアクリル板
- 最下部の固定: 300mm のL字カラーアングル
  （天板の組付けだけでは最下部が空中分解を起こすため）

## 3Dプリント部品の役割

`assets/steel-rack/500x400/` の各パーツ（コーナーブラケット大小・
ボルトスペーサー・セパレーター・穴あけガイド）は、この異種部材どうしの
接合部でボルトやナットを固定するための部品群。形状・寸法の実装は
`.scad` が正本で、各部品の機能説明は同ディレクトリのREADMEが持つ。

## 将来構想

ManjaroとWindows11の2台を、オープンフレームケース + スライドレールで
このラックへはめ込み、可搬性がありつつ手前に引き出してメンテもできる
PCケースとして展開する。既製品どうしが素直にくっつくわけではないため、
パーツとパーツの間の接合部を3Dプリント品で埋め、ボルトで固定できるように
することが最終目標。

## スライドレール組付けの寸法と算段（2026-08-12）

オープンフレームが地べたで稼働中のため早急に組み立てたい。スライドレールを
L字アングルへ組み付ける段の設計情報（実測はデジタルノギス）。

### 実測寸法

- 手前開口部の横幅: 445〜446mm程度。ケース410 + レール厚12×2 = 434で、
  猶予約1cmを残してギリギリ入る
- L字アングルの中の開口部: 70×300mm（角はradius加工）
- L字アングルの外側から開口部まで: 8.0mm
- スライドレール外寸: 400×45×12
- レール付属の木ネジ: スクリュー外径3.9mm、全長15.4mm、皿ネジ（皿高さ2.7mm）。
  レール側の口への皿の掛かり量は未測定
- オープンフレームケース外寸: 410×320×30。サイド面にネジ穴なし
- オープンフレームの外から11×11mmの地点にφ12mm穴
  （外側→穴外側の実測5mm + 半径6mm = 中心11mmの算出）。外壁は約1.2mm

### 組付けの算段

- **L字アングル開口部**: 外からM6ボルト2本を突き刺し、240mm間隔
  （300 − 60）の穴を持つ3Dプリント品で受けて上下左右のずれを止める。
  プリント品の奥側に六角ナットを差し込む窪みがあり、がっちりハマる。
  アングル内側にプリント品を置き、4mmの隙間の後にナットの六角穴を窪みに
  入れて固定する。プリント品は開口部から13mm内側へはみ出して
  スライドレールを受ける
- **木ネジ側**: 3Dプリント品にはスクリュー径の70〜80%の六角穴が都合よく、
  **二面幅3mm**の六角穴を開けて対応する（当初の「対角3mm」は二面幅の
  誤りとして user が訂正。二面幅3mm = 対角約3.46mm、3.9mmネジの約77%で
  狙いのレンジ内。`modules/bolts.scad`の`hex_hole`は二面幅指定なので
  そのまま渡せる）
- **L字アングルの板厚**: 2.2mm（M6ボルトの経路は板厚2.2 + 隙間4 +
  プリント品のナット窪みまでの肉厚で決まる）
- **スライドレール〜オープンフレーム**: 当初はツライチに収めたかったが、
  オープンフレームの横板に穴が一切ないため**乗せる方式**に変更。
  オープンフレームの内側の高さは18.8mmで、木ネジのくる上端にフレームの
  横縁が来るとして、その中で**19mm浮かせて支える**。φ12穴へのボルト固定
  （M8/M10トラス小ネジ想定、外壁約1.2mm）は当初案として記録に残す
- **奥行き方向**: フレーム320mmに対しレール400mm。ド真ん中で固定すると
  前後40mmずつ余り、グラボのせり出し実測38mm（物差し）< 40mmで成立
- **部品分割**: 240mm間隔を1部品で持つ一体型は印刷不可能なため2つに分割。
  さらにスライドレールの前後でネジ穴位置が違うため前後で2種、**合計4部品**
- **スライドレール外側のネジ穴位置**（実測）:
  - 手前側: 手前から34mm地点と98mm地点（間隔64mm）
  - 奥側: 奥から76.5mm地点と172.5mm地点（穴間96mmを実測して加算。
    ノギスが150mmまでのため穴→穴で計測）
- **M6固定部の断面設計**（確定）: どのパーツもM6穴は2つで、ボルトで上下の
  ずれを止めてガッチリ固定する。ボルトはM6×12を使い、パーツ厚は**10mm**。
  穴は2段構造 — 手前5mmがボルトの通る二面幅6mmの六角形、奥5mmが
  二面幅10mmの六角形（M6ナット: 二面幅10mm・高さ5mmがガッチリハマる）。
  ボルト経路: アングル板厚2.2 + 通し5 + ナット掛かり約5 ≒ 12mm。
  ※「240mm間隔・パーツ中央から±120mm」の旧算段は、L字再説明での
  「高さ22.5±12mmの上下2穴」に**置き換え済み (superseded)**
- **高さ合わせ**: 穴と穴が300mmでもう100mm程欲しいところだが、
  スライドレールの高さ（45mm）に合わせる方針（450mmはuser記載のまま、
  実装時に要確認とマークした）
- **接合パーツの形状**（再説明で確定）: 大きな**L字形状**の3Dプリント品を
  あてがってスライドレールとL字アングルを接合する。
  - 高さ45mm（レール断面高さに一致）
  - 3Dプリント品は積層方向を切断する荷重に超弱いため、この用途はL字一択。
    L字の内側はφ4のradiusでなだらかにして耐久力をさらに上げる
  - **短辺**: 厚さ10mm。高さ22.5mm地点から各12mmの高さ（=22.5±12、
    中心10.5mmと34.5mmの上下2穴と解釈、要確認）にM6ボルト穴。
    六角形は**対角が上下**になる向き（積層に有利なpoint-up配置）
  - **長辺**: 厚さ10mm。高さ22.5mm地点に木ネジ穴を横に通す。六角形は
    対角が上下。ネジ先端が飛び出して危険なため、ネジ位置には**φ14の
    半円柱**を被せて先端を包む（木ネジ全長15.4mm > 板厚10mmの対策）
- **実装で確定した派生値**（`modules/slide_rail_outer_bracket.scad`）:
  短辺のY寸法40mm・M6中心はレール面から27mm（= 長辺厚10 + R4 +
  余白8 + 六角半幅5の導出値）。長辺終端は最奥の木ネジ縁 + 余白8
  （手前107.5mm・奥182mm）。木ネジ六角穴の深さは14mm（フランジ10 +
  ガード内4、先端側に3mmの肉を残す）。M6が高さ22.5±12の対称配置のため
  部品はZ反転対称になり、**上下反転するだけで左右のレールに共用できる**
  （ミラー印刷不要、ユニーク部品は手前・奥の2種のみ）
- **Q&Aで確定した寸法規則**:
  - 短辺のM6穴は高さ22.5±12mm（中心10.5mmと34.5mmの上下2穴）で確定
  - 縁の余白: 穴の外側から5mm幅でもかなり頑丈だが、**10kgの荷重を
    4箇所で耐え続ける**目標のため余裕を持って**8mm**とする
  - 位置基準: スライドレール全長はぴたり400mm。500x400の天板をハメた
    時点で動かしようがなく隙間も生まれないため、**L字アングルの外側から
    34/98mm地点（手前パーツ）がそのまま木ネジ穴の位置**になる
    （奥パーツは奥側の基準から76.5/172.5mm）
