# スチールラック 500x400

## 目的

既製品のサーバーラックは高価なため、強度の必要な箇所はホームセンターで
買える汎用材（L字アングル等）で実装し、安くスチールラックを組み上げる。
特定の製品（メーカー・型番）に対応するものではない。

## 現状まとめ（2026-08-23）

外側ブラケットでレール間413mmを確保した。内側サポートの上に、
オープンフレームPC 2台がラックへ収まった。完了したのはここまでで、
設計はまだ続く。

### 現行の確定部品

- **外側**（`slide_rail_outer_{front,rear}`）
  - L字断面。短辺は厚さ10mm、長辺は厚さ8mm、高さ45mm、内側R4。
  - M6は2段六角。通し穴は6.4mm、ナット窪みは10.4mm。
  - アングルの実穴を再利用するため、`rail_offset = 14` としてレール接触面
    だけを外側へ出す。
  - 横止めはM4。通し穴4.4mmは全厚を貫通し、ナット窪みは7.4mm×深さ2.8mm。
  - ネジ穴の座標は、手前が37/101.5mm、奥が79.5/176mm。
- **内側**（`slide_rail_inner_{support,rear_l,rear_r}`の3設計・物理6個）
  - 土台は42×10×14mm。M4穴は±14mm・z=7mmに配置する。
  - ボルトはレールの向こう側から挿入し、ケース側のナットでレールと土台を
    挟み込む。
  - 柱は24×24mmで、z 0..34mmの全高で立ち上げて接地する。
  - ナット窪みを外側へ押し出した六角トンネルが柱を貫く。
  - R2は柱の4隅と、土台のナット側2隅だけに入れる。
  - 柱の偏心は、対称型が0mm、奥用が±21mm。
- **共通**
  - 通し穴は呼び寸法+0.4mm。M4は4.4mm、M6は6.4mm。
  - ナット窪みは実測+0.6mm。M4ナットは実測6.8mmで窪み7.4mm、
    M6ナットは実測9.8mmで窪み10.4mm。
  - 六角はすべて flat-up。

## 現行構成

- 縦柱: ホームセンターで見かけたL字アングル 600mm ×4本を縦に配置
- 天板: はざいや（アクリル板を加工・納品してくれるサイト）に発注した
  500x400 のアクリル板
- 最下部の固定: 300mm のL字カラーアングル
  （天板の組付けだけでは最下部が空中分解を起こすため）

## 3Dプリント部品の役割

`assets/steel-rack/500x400/` の各パーツ（コーナーブラケット大小・
ボルトスペーサー・セパレーター・穴あけガイド）は、この異種部材どうしの
接合部でボルトやナットを固定するための部品群。形状・寸法の実装は
`.scad` が正本で、各部品の機能説明は同ディレクトリのREADMEが持つ。

## 将来構想

ManjaroとWindows11の2台を、オープンフレームケース + スライドレールで
このラックへはめ込み、可搬性がありつつ手前に引き出してメンテもできる
PCケースとして展開する。既製品どうしが素直にくっつくわけではないため、
パーツとパーツの間の接合部を3Dプリント品で埋め、ボルトで固定できるように
することが最終目標。

第1段階であるPC2台のラック収容は2026-08-23に到達し、可搬性と引き出しメンテの
構想はここから続く。

## スライドレール組付けの寸法と算段（2026-08-12）

オープンフレームが地べたで稼働中のため早急に組み立てたい。スライドレールを
L字アングルへ組み付ける段の設計情報（実測はデジタルノギス）。

### 実測寸法

- 手前開口部の横幅: 445〜446mm程度。ケース410 + レール厚12×2 = 434で、
  猶予約1cmを残してギリギリ入る
- L字アングルの中の開口部: 70×300mm（角はradius加工）
- L字アングルの外側から開口部まで: 8.0mm
- スライドレール外寸: 400×45×12
- レール付属の木ネジ: スクリュー外径3.9mm、全長15.4mm、皿ネジ（皿高さ2.7mm）。
  レール側の口への皿の掛かり量は未測定
- オープンフレームケース外寸: 410×320×30。サイド面にネジ穴なし
  ※横幅はのちに**412mm前提へ更新**（2026-08-15、下記「レール間隔の実測と
  断面変更」）
- オープンフレームの外から11×11mmの地点にφ12mm穴
  （外側→穴外側の実測5mm + 半径6mm = 中心11mmの算出）。外壁は約1.2mm

### 組付けの算段

- **L字アングル開口部**: 外からM6ボルト2本を突き刺し、240mm間隔
  （300 − 60）の穴を持つ3Dプリント品で受けて上下左右のずれを止める。
  プリント品の奥側に六角ナットを差し込む窪みがあり、がっちりハマる。
  アングル内側にプリント品を置き、4mmの隙間の後にナットの六角穴を窪みに
  入れて固定する。プリント品は開口部から13mm内側へはみ出して
  スライドレールを受ける
- **木ネジ側**: 3Dプリント品にはスクリュー径の70〜80%の六角穴が都合よく、
  **二面幅3mm**の六角穴を開けて対応する（当初の「対角3mm」は二面幅の
  誤りとして user が訂正。二面幅3mm = 対角約3.46mm、3.9mmネジの約77%で
  狙いのレンジ内。`modules/bolts.scad`の`hex_hole`は二面幅指定なので
  そのまま渡せる）
- **L字アングルの板厚**: 2.2mm（M6ボルトの経路は板厚2.2 + 隙間4 +
  プリント品のナット窪みまでの肉厚で決まる）
- **スライドレール〜オープンフレーム**: 当初はツライチに収めたかったが、
  オープンフレームの横板に穴が一切ないため**乗せる方式**に変更。
  オープンフレームの内側の高さは18.8mmで、木ネジのくる上端にフレームの
  横縁が来るとして、その中で**19mm浮かせて支える**。φ12穴へのボルト固定
  （M8/M10トラス小ネジ想定、外壁約1.2mm）は当初案として記録に残す
- **奥行き方向**: フレーム320mmに対しレール400mm。ド真ん中で固定すると
  前後40mmずつ余り、グラボのせり出し実測38mm（物差し）< 40mmで成立
- **部品分割**: 240mm間隔を1部品で持つ一体型は印刷不可能なため2つに分割。
  さらにスライドレールの前後でネジ穴位置が違うため前後で2種、**合計4部品**
- **スライドレール外側のネジ穴位置**（実測）:
  - 手前側: 手前から34mm地点と98mm地点（間隔64mm）
  - 奥側: 奥から76.5mm地点と172.5mm地点（穴間96mmを実測して加算。
    ノギスが150mmまでのため穴→穴で計測）
- **M6固定部の断面設計**（確定）: どのパーツもM6穴は2つで、ボルトで上下の
  ずれを止めてガッチリ固定する。ボルトはM6×12を使い、パーツ厚は**10mm**。
  穴は2段構造 — 手前5mmがボルトの通る二面幅6mmの六角形、奥5mmが
  二面幅10mmの六角形（M6ナット: 二面幅10mm・高さ5mmがガッチリハマる）。
  ボルト経路: アングル板厚2.2 + 通し5 + ナット掛かり約5 ≒ 12mm。
  ※「240mm間隔・パーツ中央から±120mm」の旧算段は、L字再説明での
  「高さ22.5±12mmの上下2穴」に**置き換え済み (superseded)**
- **高さ合わせ**: 穴と穴が300mmでもう100mm程欲しいところだが、
  スライドレールの高さ（45mm）に合わせる方針（450mmはuser記載のまま、
  実装時に要確認とマークした）
- **接合パーツの形状**（再説明で確定）: 大きな**L字形状**の3Dプリント品を
  あてがってスライドレールとL字アングルを接合する。
  - 高さ45mm（レール断面高さに一致）
  - 3Dプリント品は積層方向を切断する荷重に超弱いため、この用途はL字一択。
    L字の内側はφ4のradiusでなだらかにして耐久力をさらに上げる
  - **短辺**: 厚さ10mm。高さ22.5mm地点から各12mmの高さ（=22.5±12、
    中心10.5mmと34.5mmの上下2穴と解釈、要確認）にM6ボルト穴。
    六角形は**対角が上下**になる向き（積層に有利なpoint-up配置）
  - **長辺**: 厚さ10mm。高さ22.5mm地点に木ネジ穴を横に通す。六角形は
    対角が上下。ネジ先端が飛び出して危険なため、ネジ位置には**φ14の
    半円柱**を被せて先端を包む（木ネジ全長15.4mm > 板厚10mmの対策）
- **実装で確定した派生値**（`modules/slide_rail_outer_bracket.scad`）:
  長辺終端は最奥の木ネジ縁 + 余白8（手前107.5mm・奥182mm）。
  木ネジ六角穴の深さは14mm（フランジ10 + ガード内4、先端側に3mmの肉を
  残す）。M6が高さ22.5±12の対称配置のため部品はZ反転対称になり、
  **上下反転するだけで左右のレールに共用できる**（ミラー印刷不要、
  ユニーク部品は手前・奥の2種のみ）
- **M6六角の向きは flat-up へ改訂**: 嵌合試験片の印刷でオーバーハングが
  激しく垂れたのを受け、userの判断で**ボルト穴の六角を90度回転**
  （対角上下 → 上下の辺が水平）。天井は短い水平ブリッジ
  （二面幅10で一辺約5.9mm）になり、ブリッジで繋げば問題は出にくい。
  flat-up化でY方向の穴半径が対角/2（5.77mm）になるため、8mm余白契約に
  合わせて短辺の導出値も更新: **M6中心はレール面から約27.8mm・
  短辺は約41.5mm**（旧27mm/40mmを置換）。木ネジ穴（二面幅3）は当初
  対象外としたが、**翌日のuser指示で木ネジ穴も90度回転しflat-upへ統一**
  （長辺終端の導出も対角基準へ: 手前約107.7mm・奥約182.2mm）。
  旧「六角は対角が上下」指定は全面的に superseded
- **穴のクリアランス実績と嵌合試験片**: 過去にM4のボルト穴を作る際は
  二面幅を0.2mm増やしていた（4mm→4.2mm）。M6でも同じ実績を当てはめ、
  通し6.2 / ナット窪み10.2で嵌合試験片を作成
  （`coupon_m6.scad`: 2段六角穴1個・高さ20mm、
  `coupon_rail_screw.scad`: 木ネジ受けの四角柱+φ14半円柱・高さ8mm）。
  試験片の嵌合が確認できたら実部品の module 定数を+0.2へ更新する
  → 実プリントの結果、**基準はさらに+0.2して呼び寸法+0.4に確定**
  （M4=4.4mm・M6=6.4mm・M6ナット=10.4mm。2026-08-14のuser指示）
- **横止めはM4小トラスネジ+ナットへ変更**（2026-08-14、実プリント結果）:
  木ネジを六角で潰すセルフタップ方式は「そのうちゆるゆるになる」上、
  キツくて無理にねじ込んだら**積層割れ**を起こした。M4小トラスネジを
  実物で当てたところスライド部分と干渉せずスルスル動いたため置換。
  L字の内側面に二面幅7.4mm・深さ2.8mmのM4ナット窪み、通しは
  二面幅4.4mmを全厚貫通。ネジ先端が突き抜けなくなったため
  φ14半円柱ガードは削除。旧・木ネジ方式（二面幅3・深さ14・ガード）は
  superseded
- **ナットの実測と窪みの根拠**（2026-08-14に実測で確定）:
  M4ナット実測6.8mm・M6ナット実測9.8mm。M6は窪み10.2でキツかった
  実績（実効+0.4）から10.4（実効+0.6）へ広げて解消しており、
  M4の7.4も同じ実効+0.6にあたるため安全圏と判断（user）。
  窪み寸法は10.4/7.4のまま変更なし — 根拠が「規格値+0.4の推定」から
  「実測基準の実効+0.6」に置き換わった
- **手前パーツの座標補正**（2026-08-14、実プリント結果）: 元木ネジの
  座標がズレていた。1個目 34→**37mm**（+3）、2個目 98→**101.5mm**（+3.5）
- **奥パーツの座標補正**（2026-08-14、実プリント結果）: 奥側も全く同じ
  兆候。奥基準で 1個目 76.5→**79.5mm**（+3）、2個目 172.5→**176mm**
  （+3.5）。userの「手前側へ移動」は**L字の底面（短辺）から遠ざかる方向**
  の意で、両パーツとも各穴を自datumから遠ざける対称な補正。
  ラック手前基準の正規化値は [224, 320.5]
- **派生値の更新**（+0.4基準・M4ナット対角による再導出）: m6_y≈28.00・
  短辺≈42.01・長辺終端は手前≈113.77・奥≈188.27
  ※m6_yと短辺は断面変更（2026-08-15）で**14.0044 / 28.0089へ置換
  (superseded)**。長辺終端は不変
- **Q&Aで確定した寸法規則**:
  - 短辺のM6穴は高さ22.5±12mm（中心10.5mmと34.5mmの上下2穴）で確定
  - 縁の余白: 穴の外側から5mm幅でもかなり頑丈だが、**10kgの荷重を
    4箇所で耐え続ける**目標のため余裕を持って**8mm**とする
  - 位置基準: スライドレール全長はぴたり400mm。500x400の天板をハメた
    時点で動かしようがなく隙間も生まれないため、L字アングルの外側
    （各パーツの自datum）からの距離でネジ穴位置を決める。
    ※当初の採寸値（手前34/98mm・奥76.5/172.5mm）は実プリントで
    ズレが判明し**superseded** — 現行値は上記「座標補正」の
    **手前37/101.5mm・奥79.5/176mm**

## レール間隔の実測と断面変更（2026-08-15）

外側2パーツの実プリントでL字アングルとスライドレール（外）の固定には成功
したが、レール間隔の実測（コンベックス）が385mm程しかなく、オープンフレーム
ケースが入らない。以後**ケース幅は412mmを前提**とする（user指示。当初記録の
410mmは superseded）。

- 目標レール間隔: 412 + 0.5×2 = **413mm**。片側 (412 − 385) / 2 + 0.5 =
  **14mm** ずつレール接触面をラック外側へ移す
  （`modules/slide_rail_outer_bracket.scad` の `rail_offset = 14`）
- **M6実穴の再利用**: アングルには実物で既にM6穴が開いているため、
  M6中心と部品外端の絶対位置は変えず、レール接触面（部品ローカルy=0）
  だけを外へ出す。派生値は旧導出式 − 14 で **m6_y 14.0044・短辺 28.0089**
  （M6外側の余白8mmと部品外端は不変）
- **長辺は2mm削り（厚10→8、user決定）**: レール面を外へ出すとM6ナット
  挿入口が長辺と重なるため。ナット六角の内縁（14.0044 − 6.0044 = 8.000）が
  長辺外面とツライチになり重なりが消える
- **フィレットはナット挿入回廊で局所カット（user許容）**: R4フィレットが
  挿入経路に掛かる分は削ってよい。ナット窪みを+X側へ延長した回廊
  （x 7.2..17）にし、退化形状の回避を兼ねて長辺外面に0.2mmの逃げ溝を彫る
- 旧断面（長辺10mm厚・m6_y 28.0044・短辺42.0089）は **superseded**。
  嵌合試験片`coupon_rail_screw.scad`の厚さも8mmへ追随

## スライドレール内側の設計（2026-08-15、着手）

外側は組付け成功（手でぐいぐいやっても動かず、ケースの左右に2〜3mmの
空間 = 想定どおり）。次はスライドレール内側とオープンフレームケースの
接合部品。

### 実測寸法（user共有）

- スライドレール（内）全長: **398mm**
- M4ネジ用の穴位置: 奥から18mm / 奥から46mm / 手前から32mm /
  手前から60mm / 中央付近に28mm差で2つ（計6穴。どのペアも間隔28mm）
- オープンフレームケースの前後: **322mm**（公称320より少し大きい実測）
- ケースをド真ん中に置く → 前後の隙間39mmずつ（user計算。要確認:
  (398−322)/2 = 38のため、基準が外側レール400mmの可能性）

### 部品の構想（user指定）

- 少し長めに作り、内側の方が上に飛び出した形状
- **ネジ穴ブロック**: 14×14×(横幅28+14=42)mmの四角いブロック。
  中央にM4穴、終わり際にナット穴
- **スタンドオフ**: 正方形10×10×(高さ14+20=34)mmを、オープンフレームから
  2mm奥まった場所に配置。**この6箇所の正方形でオープンフレームケースを
  浮かせる**
- **部品数**: 左右反対に作れる（反転で共用できる）のは中央パーツだけ。
  物理6個 = 手前L/R・中央×2・奥L/Rのうち、ユニーク設計は**合計5パーツ**
  （手前L・手前R・奥L・奥R・中央）
- **Q&Aで確定（2026-08-15）**:
  - スライドレール(内)の高さは**実測24.4mm**で、そのド真ん中（12.2mm）に
    横穴。ブロック14mmは穴中心に付き、下側は浮く（レール下端から約5.2mm）。
    上部を薄くすればレール上端にツライチへ近づくが**調整次第**
  - ナット窪みの向きは外側ブラケットと同じ（レール側から通し4.4、
    終わり際に7.4×2.8の窪み）
  - スタンドオフの2mm奥まりは**現物合わせ**前提（スカスカで横にグラグラ
    動くなら2mmは狭まる可能性）— パラメータとして持つ
  - 前後の隙間は**一旦39mm**で考える（(398−322)/2=38だが、キツそうなので
    39。基準は外側レール400相当）

### 実装で確定した値（2026-08-15、3設計・物理6個）

「ド真ん中を手前に配置して、奥だけ帳尻合わせ」というuserの号令で、
**ユニーク設計は5パーツ→3設計へ縮小**（旧「合計5個」は superseded）。
実装は `modules/slide_rail_inner_block.scad` +
`assets/steel-rack/500x400/slide_rail_inner_{support,rear_l,rear_r}.scad`、
検証は `tests/slide-rail-inner.sh`。

- **部品ローカル座標**: X = レール方向（M4 2穴の中点が0）、Y = 0 がレール(内)
  の接触面で +Y がラック中央向き、Z = 0 がブロック底面。奥用の規約として
  **部品ローカル +X = ラック手前方向**
- **ブロック**: 42（X）× 14（Y）× 14（Z）。X ∈ [−21, 21]
- **M4穴×2**: X = ±14（間隔28）・Z = 7・軸Y。ブロック中心の高さ7mmを

  全厚貫通し、終わり際（y=14の面）に 7.4 × 深さ2.8 のナット窪み。

  レール接触面とツライチ。柱の位置は `standoff_offset`（ブロック中心基準）
- **3設計の内訳（物理6個）**:
  - `slide_rail_inner_support.scad`: `standoff_offset = 0`。X鏡像不変のため
    **手前L/R + 中央L/R の4個**をこの1設計で印刷できる（ミラー印刷不要）

### 2026-08-15 実物フィードバック — ナット向きの反転と柱の離隔

印刷した実物を当てたuserから「惜しい」の評価とともに2点の指摘が来たため、
上の「実装で確定した値」のうち**ナット窪みの向き**と**柱のY位置**を改めた
（user原文は末尾 verbatim の「2026-08-15 実物フィードバック（ナット位置と
柱の離隔）」）。ブロック外形・M4穴位置・偏心14・左右鏡像の関係は不変。

- **ナット窪みはレール接触面（y=0）側へ反転**: 二面幅7.4・深さ2.8の窪みが
  y 0..2.8 に開き、通し二面幅4.4は全厚貫通のまま。ナットを窪みへ入れてから
  レールへ当てるとレール板が背中を押さえるので脱落せず、ネジは**ケース側
  （y=14の面）から刺して**締める。締結はナットとレール板の圧接 +
  シャンクのせん断で受ける。旧向き（レール側から通し → y=14の面にナット窪み。
  外側ブラケットと同じ向き）は **superseded**
- **柱をレール接触面から2mm離す**: module の名前付き定数
  `standoff_setback = 2` を導入し、柱を Y ∈ [2, 12] へ移した。「多少離す」の
  暫定値で**現物合わせ**予定。離隔の上限は
  `standoff_setback + standoff <= block_depth`（= 最大4mm）の assert で
  固定してあり、これを超える必要が出たら支持方法そのものの再設計になる
- **検証の追随**: 断面実測を y=1.4（窪み六角 対角8.54 が X=±14・Z=7）と
  y=12.6（通し六角 対角5.08 **のみ** = 窪みが y=14 側に無いことの直接検証）
  へ更新し、z=25 の柱断面を Y ∈ [2, 12] で固定。CONTRACT echo にも
  `standoff_setback` を追加した

### 2026-08-16 柱とナットの干渉解消（足痩せ形状） — superseded
