# ゲームデスクのイヤホン・マイク置き

## 目的

ゲーム用デスクの天板に市販のデスククランプを固定し、その立ち上がり板に
3Dプリント品を1本の皿ネジで留める。Bluetoothイヤホンのケースと
Bluetoothピンマイクのケースを、クランプの左右に立てて受ける。どちらの
ケースも、蓋がホルダーの上にはみ出す高さまで沈める。蓋を押し出して開けたまま、
中身を取り出す使い方を想定する。

## 部品構成

単一のプリント部品（`assets/game-desk/earphone_mic_holder.scad`）で構成する。
中央はクランプ取付座、左はイヤホンケースのポケット、右はピンマイクケースの
ポケットである。

座標系は部品自身のdatumで定義する。X=0が取付座の左右中心で、-Xがイヤホン側、
+Xがピンマイク側である。Y=0がクランプ板への当たり面で、-Yへ本体（取付座と
ポケット）が伸びる。+Y側は、クランプ板を逃がす帯と、その左右でデスク面へ
当たる段になる。Z=0が部品底面で、上端はZ=40の一平面である。この上端は
クランプ板の上端と同一平面ではなく、4.5mm低い（v0.4で変更。理由は後述）。

印刷時は底面をビルドプレートに置き、ポケットの開口を上へ向ける。壁、ポケット、
切り欠きはすべて垂直面で構成する。水平な天井を持つのはM8の六角穴だけである。
六角はすべてflat-upとし、天井は短い水平ブリッジになる（スチールラックの部品と
同じ流儀）。

## 確定解釈（2026-08-23）

- **前後の定義**: 前 = デスク接触面（Y = 4.2）の側、後 = その反対側である。
  ケースを差し込む向きに依存するfeature（イヤホン側のUSB-C長穴、ピンマイク側の
  凸チャンネル）は、すべて前壁の内面（Y = 1.2）を基準に置く。「前後を反転する」
  とは、この前後の割り当てを入れ替えることを指す。完成形状全体を反転することでは
  ない（後述の第2弾を参照）。
- **クランプ取付座**: クランプ板の寸法は40×24×4.2で、中央にM8のメスネジが
  ある。取付座は板と同じ40×24の面を覆う。M8の中心は板の中央に一致させる。
  部品座標での中心Zは、v0.3までは(X, Z) = (0, 20)だった。v0.4で天端を4.5mm
  下げたため(0, 24.5)になる（20はsuperseded）。
- **皿ネジの向き**: 皿ネジは部品の外側からクランプ板のM8メスへ差し込む。
  そのため、皿の逃げは部品の外面側だけに開き、クランプ当たり面（Y=0）側には
  現れない。
- **取付座の板厚**: 6mmとした。皿の逃げ4.5mmを加工すると、残り肉は
  1.5mmになる。皿ネジは皿込みで8.6mm（軸部4.1mm）しかないため、座を厚くすると
  軸がクランプ板に届かなくなる。板厚8mmでは、掛かりは8.6 - 8 = 0.6mmしかなく、
  ネジが効かない。板厚6mmでは、8.6 - 6 = 2.6mmがクランプ板4.2mmのM8メスに
  掛かる。掛かりを増やすには、座を薄くするか、より長いM8皿ネジに替える。実物
  合わせで再評価する。
- **クリアランス**: ケースの内寸はすべて、実測値に0.4mmを加えた値とする。少し
  スカスカなくらいがよいというuserの判断による。イヤホンは61.4×29.9、ピン
  マイクは81.2×38.1になる。
- **USB-Cの長穴**: イヤホンケースの底面の横中央に、幅14mmの長穴を開ける。長穴は
  前壁の内面から7.5mm〜16.0mmの位置に置く（長さ8.5mm）。前面9mm・奥面15mmの
  実測値から穴を8mmへ広げる再計算をuserが行い、両側へ1.25mmずつ振った値である。
  奥面から13.5mmという指定も同じ穴を指す。ただし、クリアランス0.4mmを奥側へ
  足した実装では、前壁基準の値を正とする。
- **凸のチャンネル**: ピンマイクケースは、背面にL字のUSB-C変換器を噛ませたまま
  落とし込む。そのため、内寸の背面中央に幅12.7mm・奥行き8.7mm（12.3/8.3 + 0.4）
  の通路を追加し、断面を凸の字にする。通路は背面壁の全高と床を貫通させ、ケーブル
  を下へ抜く。床の残りはケースの受けとして残す。
- **背面壁の厚み**: チャンネルは背面壁を彫るのではなく、背面壁を厚くしてその中を
  通す。外壁3mmを残すため、右ポケットの背面は3 + 8.7 = 11.7mmになる。背面は
  デスクの反対側である（第2弾の反転後）。
- **R**: 外側の垂直エッジは半径2mmで落とす。角が刺さると痛いためである。デスク
  接触面（底面）の水平エッジは加工しない。ポケット内側のコーナーは、ケースが丸い
  ため半径4mmとする。
- **命名**: userが言う「ゲームデスクディレクトリ」を英語化して、
  `assets/game-desk`とした。部品名は留め方ではなく「何を置くか」を主語に
  する。デスク用のクランプはUSBポート置きなど他にも作る予定があり、
  クランプを主語にすると区別できなくなるためである。長すぎない名前として
  `earphone_mic_holder`を選んだ（初版の`desk_clamp_holder`から改名）。

## 実装値（2026-08-23、v0.4）

現物合わせを前提とした暫定値である。すべての名前付き定数は`.scad`で定義し、
CONTRACT echoとして出力する。テストは実形状で裏を取る。

- 壁厚3mm。床厚はイヤホン側6mm・ピンマイク側8mm。外形は178.6 × 52.8 × 40mmで、
  bboxはX -79.4〜99.2・Y -48.6〜4.2・Z 0〜40である。デスク側の段4.2mmは
  ポケットの外形の中に含まれる（別の帯として足していた旧構成の57mmは
  superseded）。
- 左ポケットは幅67.4mm・全高40mm、内寸61.4 × 29.9・深さ34mm。
- 右ポケットは幅87.2mm・全高40mm、内寸81.2 × 38.1・深さ32mm。
- M8の通し六角は二面幅8.4mm。皿の逃げは、外面の二面幅16.0mmから深さ4.5mmで
  通し8.4mmへ直線的に絞る六角錐台である（第2弾で直壁から変更）。中心は
  部品座標で(X, Z) = (0, 24.5)である。
- 天端の下げ量`top_drop`は4.5mm。クランプ板は部品座標でZ 4.5〜44.5に掛かる。
- 補強ガセットは脚2mmの45度直角三角形で、取付座の外面（Y = -6）と両ポケットの
  側壁（X = ±12）が作る凹角に左右対称で入る。右の頂点は
  (12, -6)-(10, -6)-(12, -8)である。斜辺はX + Y = 4の45度線になる。
- 外形は、取付座・両ポケット・デスク側の段の矩形を2Dで足した後、opening
  （縮めてから膨らませる）を掛けて作る。これにより凸の角だけが丸まり、座と
  ポケットの取り合いにある凹の角は直角のまま残る。接合部の肉は痩せない。
- クランプ板の逃げは、openingの後に切る。板の角は直角なので、逃げの4隅も
  直角のまま残す。
- 上端が一平面になったため、外形は全高40mmの一様な押し出し1本で足りる。

## 実プリントの反映（2026-08-23、v0.2）

初版を印刷し、クランプへ取り付けたuserが3点を指摘した。原文は末尾の
verbatimに置く。反映の内容は次のとおりである。

- **前後の反転（解釈誤り・superseded）**: 「完成形状の全体をY方向へ反転する」と
  解釈して`mirror([0, 1, 0])`を掛けた。しかし外形がほぼY対称なため見た目は変わらず、
  向きに依存するfeature（長穴・チャンネル）もポケットと一緒に動くので、ケースから
  見た位置が変わらない。つまり何も反転していない。この解釈と`mirror`はsuperseded
  である。正しい反映は第2弾に書く。
- **上端の統一**: 上端の高さを揃えることが必須要件である。取付座だけが
  ポケットより高い旧構成（右35mm・左37mm・座40mm）はsupersededとし、上端を
  クランプ板の上端と同じZ=40の一平面へ揃えた。収納深さ34mmと32mmは変えず、
  床厚をイヤホン側6mm・ピンマイク側8mmへ厚くして高さの差を吸収する。増えるのは
  インフィルだけなので、重量と材料の問題にはならないというuserの判断による。
- **デスク側の段**: クランプ板の左右では、部品が板厚4.2mmだけデスク面から
  浮いていた。中央の24.4mm（板24mm＋クリアランス0.4mm・片側0.2mm）の帯だけを
  板厚の分だけ逃がし、その外側の左右は取付面をデスク側へ4.2mm寄せた。
  クリアランスを左右へ0.4mmずつ振ると帯が24.8mmになり、板が帯の中で泳ぐ。
  そのため、クリアランスは総量で0.4mmとする。段の向きを逆にすると、隙間は
  8.4mm相当へ悪化する。

## 実プリントの反映（2026-08-23、v0.3）

第1弾を反映した部品をクランプへ取り付けたuserが、反転が効いていないことと、
仕上げの2点を指摘した。原文は末尾のverbatimに置く。

- **差し込み向きの反転**: userが求めていたのは「ケースを差し込む向きの前後反対」
  である。クランプ取付座（M8座・当たり面Y=0・中央24.4mmの逃げ）はデスク側の
  基準なので動かさず、各ポケットの中でケース形状だけを前後入れ替える。結果、
  イヤホン側のUSB-C長穴は反対側の内壁基準へ移り、前壁の内面（Y = 1.2）から
  7.5〜16.0mm、すなわちY = -6.3〜-14.8mmになる。ピンマイク側の凸チャンネル
  （12.7 × 8.7）はデスク側の壁から反対側の壁へ移り、Y = -36.9〜-45.6mmを通る。
  完成形状全体の`mirror`は削除し、`.scad`は最終座標系のまま書く。
- **デスク側の壁厚**: デスク側の壁が7.2mmもあった。「当たり面から+Yへ4.2mmの帯を
  足す」方式が、ポケットを当たり面基準（Y = 0）に置いたまま帯の分だけ前へ肉を
  足していたためである。ポケットの外形をデスク接触面（Y = 4.2）から始め、
  「壁3 → ケース内寸 → （チャンネル） → 壁3」の順に並べ直した。これで実壁厚は
  デスク側・反対側ともに3mmへ揃う。帯そのものは残す。ポケットのブロックだけでは
  取付座の幅の範囲にデスク接触面が無い。そこが凸の角になってopeningでR2に丸まり、
  クランプ板の逃げの内側の角が板の直角と合わなくなるためである。
  デスク側の段4.2mmがポケットの外形に吸収されるので、外形の全深さは57mmから
  **52.8mm**へ縮み、bboxのYは-52.8〜4.2から-48.6〜4.2へ移る。CONTRACTの`outer`も
  `max(ear_out_d, mic_out_d)`の導出値にして52.8を申告する。M8座（板厚6・逃げ
  24.4 × 4.2）、上端Z40、床厚6/8はuser確認済みなので不変。
- **皿の収まり**: 直壁の六角ボア（16.0 × 深さ4.5）をやめ、外面の
  二面幅16.0mmから深さ4.5mmで通し8.4mmへ直線的に絞る六角錐台にした。断面が
  なだらかな三角形になり、皿がそのまま座る。残り座厚1.5mmの通し8.4mmは従来
  どおりである。二面幅は深さdに対して16.0 - d × (16.0 - 8.4) / 4.5 で、深さ
  2.25mmでちょうど12.2mmになる。

## 実プリントの反映（2026-08-23、v0.4）

第2弾を反映した部品をuserが確認し、「理想の形状に近づいてきました」として2点を
指摘した。原文は末尾のverbatimに置く。

- **天端を4.5mm下げる**: クランプの上腕がデスク天板の上に乗るため、天端を
  クランプ板の上端に揃えると、その厚みぶん部品が天板からはみ出して邪魔になる。
  部品ごと4.5mm下げる。ここで動かすのは部品とクランプ板の相対位置だけであり、
  部品自身のdatum（底面Z = 0 = プリント面）は動かさない。ポケットの深さ34mmと
  32mm、床厚6mmと8mm、全高40mmはすべて不変である。userの言う「天板を下げた分、
  底面が下がる」は、この「深さを削らずに部品ごと下げる」ことを指す。したがって
  観測できる変化はM8の中心Zだけで、20mmから**24.5mm**（= 40 + 4.5 - 20）へ
  上がる。クランプ板は部品座標でZ 4.5〜44.5に掛かる。
  「上端 = クランプ板上端と同一平面」というv0.2の必須要件はsupersededで、
  正しくは「上端は一平面であり、クランプ板上端より4.5mm低い」である。
  この読み替えを採ったのは、プリント底面をZ = 0に置くリポジトリの規約と、
  断面テストの座標系（bboxのZ 0〜40）を保つためである。
- **凹角の45度補強**: 取付座の外面（Y = -6）と両ポケットの側壁（X = ±12）が
  作る凹角で、左右のポケットが中央の薄い座だけで繋がっていた。脚2mmの45度
  直角三角形を左右対称に足す。右は(12, -6)-(10, -6)-(12, -8)で、斜辺は
  X + Y = 4の45度線である。2Dの外形では、opening（縮めてから膨らませる）の
  **後**にunionする。45度の細い三角を先に足すと、縮めた段階で消えてしまう
  ためである。全高40mmの押し出しに乗るので、面はすべて垂直のままであり、
  プリント難度は変わらない。
  皿の逃げとは干渉しない。皿の六角錐台は外面でX方向に対角18.475mm、すなわち
  |X| ≤ 9.238mmまでしか広がらず、ガセットの内端X = ±10mmに届かない。この
  余裕は`.scad`のassertで固定してある。ガセットは凹角の中に収まるので、外形の
  bboxは178.6 × 52.8 × 40mmのまま変わらない。

## 検証

`tests/game-desk.sh`はSTLの断面を実測する。測定対象は次のとおりである。

- 取付界面（M8の通し六角の位置Z = 24.5と、皿の錐台を3つの深さで測った二面幅
  15.156 / 12.200 / 9.244mm）
- 補強ガセットの平面（Z = 20）。凹角(±12, -6)に頂点が無いこと、(±10, -6)と
  (±12, -8)が鋭角の頂点であること、斜辺の内外の材料の有無を測る。
- 補強ガセットの斜辺の角度。Y = -7とY = -7.5のX-Z断面で、右ブロックの内側の
  縁がX = 11とX = 11.5へ寄る。0.5下がると0.5寄るのが45度の実測である。
- 外形bbox（X -79.4〜99.2・Y -48.6〜4.2・Z 0〜40。ガセットは凹角の中に
  収まるので不変である）
- ポケットの内寸と深さ、床厚6mmと8mmの境目
- 上端がZ = 40の一平面であること（クランプ板の上端より4.5mm低い）
- 前壁・後壁の実厚がどちらも3mmであること（材料の跨ぎを両ポケットで測る）
- 長穴の位置（前壁内面基準でY -6.3〜-14.8）
- 凸のチャンネルの貫通（Y -36.9〜-45.6、後壁側）
- デスク側の段（中央24.4mmの帯が板厚4.2mm分だけ空で、その外側は材料である）
- 外側R2
- 単一連結成分

npm testに組み込んである。検査の有効性は、変種を単独注入してredになることで
確かめてある。第1弾では反転の欠落・床厚の旧値・段の欠落・段の逆向き、第2弾では
差し込み向きの旧配置・旧「4.2mm帯」方式の厚壁・直壁の皿ボアを注入した。
第3弾では、M8中心Zを旧値20へ戻す変種と、ガセットのunionを外す変種を注入した。
前者は取付界面の4断面とm8_centerのCONTRACTがred、後者はガセットの平面検査と
2つのX-Z断面がredになった。

## 未解決

- クランプ本体（板以外）の形状は共有されていない。取付座の下部や左右がクランプの
  本体と干渉しないかは、実物合わせで確認する。
- 皿ネジの掛かり2.6mmで実用に足りるかは未検証である。足りなければ、座を薄くするか、
  長いM8皿ネジに替える。
- ホルダーはクランプ板で支持し、左右の取付面はデスク面へ当たる。自重とケースの
  重さでどれだけ傾くかは、段を入れた実物で確認する。
- 逃げの帯24.4mmが実物のクランプ板に対して緩すぎないかは未検証である。板が帯の
  中で泳ぐなら、クリアランスを減らす。

### Q&Aの回答

> Q1: 前後寸法の計算ありがとうございます。USB-typeCのジャックの穴は厚さがあり、前面->穴の手前側が9mm、奥面->穴の奥側が15mmです。
>   USB-typeCのケーブルはこの穴より広く、角が丸まって丸いケースなので計測誤差があるとしても8mmに拡張することでtypeCケーブルを緩衝なく挿せるのかなと考えました。
>   従って穴の位置を再計算すると、前面9-1.25 -> 余裕を持たせて7.5mm地点、奥面15-1.25 -> 余裕を持たせて13.5mm地点に座標を打って穴を開ければケーブルが緩衝しないのかなと考えました。
> Q2. 皿ネジは外側からクランプ部分のM8メスのネジ穴に向かって差し込む形です。
> Q3. クリアランスは0.4mmで見てください。少しスカスカなくらいがよさそう
> Q4. 上下に貫通させちゃってください。L字のアダプターを装着したまま上からストンと落とし込むイメージ
>   だからアイテム2はタダのradius付きの四角形の穴ではなく、凸の漢字のように少し中央にさらに切り欠きがあるようなイメージになります。
> さらに全体的な話ですが、外側の角は刺さると痛いので2mm程度のraduisを設定してください。
> (デスクとひっつく部分はrasius不要)
