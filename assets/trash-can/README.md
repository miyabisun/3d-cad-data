# 30Lゴミ袋用ゴミ箱

nocoo sanipac 30L（平置き幅550×長さ700mm）を掛ける、内寸240×240×480mmの角形ゴミ箱です。
床厚4mmの箱を上下2段に分けて印刷し、スナップで連結します。袋は縁から外へ70mm折り返し、
袋の底はゴミ箱の床に接します。蓋は折り返しを覆って押さえ、中央の穴からゴミを入れます。
最下段の前後の内壁には、袋のパック（210×300×6mm）を差すポケットがあります。

取得・STL生成の共通手順は[ルートのREADME](../../README.md)を参照してください。
以下のコマンドはリポジトリのルートで実行します。

## 印刷する部品

| ファイル           | 外寸 (mm)           | 印刷向き                                  |
| ------------------ | ------------------- | ----------------------------------------- |
| `bottom_ring.scad` | 248.4 × 248.4 × 250 | 使用時の向き。床4mm、上端12mmは連結用の舌 |
| `top_ring.scad`    | 248.4 × 248.4 × 246 | 上下逆（上端を下）。スカートが上になる    |
| `lid.scad`         | 253 × 253 × 78      | 天板を下にする                            |

`trash_can.scad`は組立表示で、印刷しません。形状と寸法は各部品が共有する[`modules/trash_can.scad`](../../modules/trash_can.scad)にあります。全部品がP1Sの256mm角に収まり、サポートは不要です。

```sh
mkdir -p dist/trash-can
for p in bottom_ring top_ring lid; do
  openscad --export-format binstl -o dist/trash-can/$p.stl assets/trash-can/$p.scad
done
python3 tests/trash-can.py
```

## 寸法

| 箇所          | 寸法 (mm)                                                |
| ------------- | -------------------------------------------------------- |
| 内寸 / 壁厚   | 240 × 240、角R10 / 3（外寸246、外角R13）                 |
| 内高さ / 床厚 | 480（2段でP1Sに収まる最大のcm値） / 4（全高484）         |
| 段の接合面    | 床下面から238。接合部は壁を外へ4.2まで張り出す           |
| ポケット内寸  | 幅220 × 厚6 × 高さ240（床の上から）、前板3               |
| ポケットのU字 | 前板の上端から幅140 × 深さ100（底はR70）                 |
| 蓋            | 内寸247（片側0.5の逃げ）、縁から下へ75を覆う、穴200角R20 |

ポケットの幅220は、内壁のR10を除いた平らな部分の全幅です。ポケットは前後で各9mm内側へ出ます。
パックは高さ300なので、上端60mmがポケットから出ます。

## 連結

接合部は壁を外へ4.2mmまで張り出し、下段の上端に内側2.05mm厚・高さ12mmの舌、上段の下端に外側2.05mm厚のスカートを並べます。
舌の横と上には0.1mmの隙間があります。張り出しは接合面の上下とも30度の斜面で壁3mmへ戻り、
外面に段差はありません。どちらの段も、印刷の向きでは30度のオーバーハングになります。
舌の4面の中央に幅20mm・出1.2mmの爪があり、上段を真上から押し込むとスカートの窓へはまります。
外すときは4か所の爪を窓から内側へ押しながら上段を持ち上げます。
最下段の前後の爪の裏はポケットなので、パックを抜いてから外します。
窓は幅21mmで、上段を上下逆に印刷すると、爪を受ける辺が21mmのブリッジになります。
ブリッジがたるんでも爪がはまるよう、この辺は爪の受け面より0.4mm下げてあり、上段は上下に0.4mm動きます。

## 調整

`modules/trash_can.scad`の冒頭で調整します。最下段を`bottom_ring_height`（初期250）とし、
`inner_height`（初期480）の残りが上段になります。
各段・蓋がP1Sの256mmを超える値、袋（`bag_length`から折返しと縁を引いた627mm）が床へ届かない値、
ポケットが最下段や平らな壁に収まらない値はエラーになります。
爪のはまり具合は`snap_depth`、ブリッジのたるみへの余裕は`snap_clearance`、蓋の嵌合は`lid_clearance`で調整します。

## 未確認

実物の印刷・連結・爪の保持力は未確認です。袋は縁から内側へ627mmあり、内高さ480に床の折れ込み分
（内寸の半分、約120mm）を足した600mmより長いため、底の四隅まで沿わせられる計算です。
蓋を被せたときの袋のたるみ、パックの出し入れも実物で確認してください。
