# 30Lゴミ袋用ゴミ箱

nocoo sanipac 30L（平置き幅550×長さ700mm）を掛ける、内寸240×240mm・高さ620mmの角形ゴミ箱です。
底板のない筒を3段に分けて印刷し、スナップで連結します。袋は縁から外へ70mm折り返し、
底は床に接します。蓋は折り返しを覆って押さえ、中央の穴からゴミを入れます。
最下段の前後の内壁には、袋のパック（210×300×6mm）を差すポケットがあります。

取得・STL生成の共通手順は[ルートのREADME](../../README.md)を参照してください。
以下のコマンドはリポジトリのルートで実行します。

## 印刷する部品

| ファイル           | 外寸 (mm)       | 印刷向き                             |
| ------------------ | --------------- | ------------------------------------ |
| `bottom_ring.scad` | 246 × 246 × 250 | 使用時の向き。上端12mmは連結用の舌   |
| `middle_ring.scad` | 246 × 246 × 197 | 使用時の向き。下端は連結用のスカート |
| `top_ring.scad`    | 246 × 246 × 197 | 使用時の向き                         |
| `lid.scad`         | 253 × 253 × 78  | 天板を下にする                       |

`trash_can.scad`は組立表示で、印刷しません。全部品がP1Sの256mm角に収まり、サポートは不要です。

```sh
mkdir -p dist/trash-can
for p in bottom_ring middle_ring top_ring lid; do
  openscad --export-format binstl -o dist/trash-can/$p.stl assets/trash-can/$p.scad
done
python3 tests/trash-can.py
```

## 寸法

| 箇所          | 寸法 (mm)                                                |
| ------------- | -------------------------------------------------------- |
| 内寸 / 壁厚   | 240 × 240、角R10 / 3（外寸246、外角R13）                 |
| 高さ          | 620 = (袋長700 − 折返し70 − 縁3) をcm単位で切り捨て      |
| 段の接合面    | 床から238と423                                           |
| ポケット内寸  | 幅220 × 厚6 × 高さ240、底3・前板3                        |
| ポケットのU字 | 前板の上端から幅140 × 深さ100（底はR70）                 |
| 蓋            | 内寸247（片側0.5の逃げ）、縁から下へ75を覆う、穴200角R20 |

ポケットの幅220は、内壁のR10を除いた平らな部分の全幅です。ポケットは前後で各9mm内側へ出ます。
パックは高さ300なので、上端60mmがポケットから出ます。

## 連結

下段の上端に内側1.4mm厚・高さ12mmの舌、上段の下端に外側1.4mm厚のスカートがあり、0.2mmの隙間で重なります。
舌の4面の中央に幅20mm・出1.2mmの爪があり、上段を真上から押し込むとスカートの窓へはまります。
外すときは4か所の爪を窓から内側へ押しながら上段を持ち上げます。
最下段の前後の爪の裏はポケットなので、パックを抜いてから外します。

## 調整

`trash_can.scad`の冒頭で調整します。高さは`bag_length`・`bag_overhang`から求め、
最下段を`bottom_ring_height`（初期250）とし、残りを上2段へ等分します。
各段・蓋がP1Sの256mmを超える値、ポケットが最下段や平らな壁に収まらない値はエラーになります。
爪のはまり具合は`snap_depth`、蓋の嵌合は`lid_clearance`で調整します。

## 未確認

実物の印刷・連結・爪の保持力は未確認です。袋の底は四隅まで沿わせず、垂らした状態で床へ届く高さです。
袋を底の四隅まで沿わせると、底の折れ込みの分（内寸の半分、約120mm）だけ袋の長さが足りなくなります。
蓋を被せたときの袋のたるみ、パックの出し入れも実物で確認してください。
