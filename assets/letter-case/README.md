# letter-case

スタック式レターケース（5段引き出し）の引き出しへ敷く Gridfinity ベース
プレート。外箱は既製品を使い、bin だけをプリントする構成の受け皿。
設計思想は `ledger/designs/letter-case-gridfinity.md` が正本。

共通値（引き出し内寸、クリアランス、合わせ込み値、マス数、分割行数と、
そこから導く板寸法・縁幅・CONTRACT 文字列）は `modules/letter_case.scad` が
持つ。単体では何も描かないので `assets/` ではなく `modules/` に置く。

## baseplate_front.scad / baseplate_rear.scad

引き出し 1 段ぶんのベースプレートを 42mm 境界で前後 2 枚に分けたもの。
どちらも底面をビルドプレートへ置き、サポート不要。

- 板の外形は引き出し内寸 − 片側 1mm に、試作の合わせ込み（左右 +1.3 ずつ、
  手前 −2.5）を足した 240.6×313.5。奥片の奥側 2 隅は R6。中央の高い床に乗り、
  縁は左右奥のくぼみの上を浮いて跨ぐ（くぼみの斜面に触れない）
- ソケットは 5×7（42mm ピッチ）。輪郭は公称 41.5/37.2/35.8 に嵌合の逃げ 0.1 を
  全周へ足した 41.7/37.4/36.0（bin がきつかったため）。前片は前縁 1.5mm + 4 行（奥行き 169.5）、
  奥片は 3 行 + 奥縁 18mm（奥行き 144）。継ぎ目側に縁は無く、突き合わせると
  継ぎ目を跨いで 42mm ピッチが続く
- 床は無い (ソケットが底まで抜け、bin は引き出しの床に直接乗る)。高さは
  ソケットの 4.65mm
- くぼみを跨ぐ左右と奥の縁は、bin の境目 (42mm ピッチ) に沿った四角い窓を
  貫通で開け、窓の対角に X の筋交いを渡して肉抜きする。枠・リブ・筋交いは
  線幅 2mm。左右の窓は 11.3×40 (前片 8、奥片 6)、奥の窓は 40×14 (5)。前縁 1.5mm
  は無垢
- 材料: 前片 42.4cm³ (≈53g PLA)、奥片 41.3cm³ (≈51g)
