# 天馬 ルームケースプチ A4-23（浅型）

[メーカー商品ページ](https://tenmafitsworld.com/SHOP/roomcase-puchi.html)の
「(2)浅」用。設計の根拠と依頼原文は
[台帳](../../../ledger/designs/temna-roomcase-puchi-gridfinity.md)を参照。
アイリスオーヤマ A4-LCJとは独立した製品・寸法設定です。
ディレクトリ名は依頼どおり `temna-roomcase-puchi` としています。

実測232×323×高さ70mmを採用し、壁との余裕を片側1mm取った
230×321×厚さ4.65mmの床なしベースプレートです。ソケットは42mmピッチ、
嵌合の逃げは全周0.1mm。測定誤差・成形の傾斜があるため、実物との嵌合は未確認です。
印刷後に合わなければ `modules/temna_roomcase_puchi.scad` の
`drawer_w` / `drawer_d` / `fit_clearance` / `socket_clearance` を調整してください。
メーカー表記の有効内寸220×315mmとは差があるため、印刷前に引き出しの底面で
232×323mmが使えることを確認してください。

| 部品 | 外形（mm） | ソケット |
|---|---|---|
| `baseplate_front.scad` | 230×168×4.65 | 標準5列＋左端数1列、4行 |
| `baseplate_rear.scad` | 230×153×4.65 | 標準5列＋左端数1列、3行＋奥縁27mm |

引き出しの手前をY=0、左をXマイナスとして配置します。奥片のY=0を前片の
Y=168に突き合わせると、継ぎ目でも42mmピッチが続きます。奥側の左右角だけR5mm。
奥縁は厚さ2mmの位置決め用X筋交い付きスペーサーで、端数セルはありません。
底面Z=0をビルドプレートに置き、サポートなしで各1枚印刷します。

左端のセル幅（ピッチ）は20mm＝20/42≒0.47619セルです。
5＋0.6セルは235.2mmとなり実測幅を超えるため、収まる端数幅を使います。
左端は上端開口19.7×41.7mm、垂直部15.4×37.4mm、底14×36mm。
角Rと45°の面取りは標準ソケットと同じです。
**左端にはXピッチ20mmに対応した専用binが必要**です。0.5セル（21mm）のbinは
入りません。既存の整数セルbinは右側5列で使用できます。
クリアランスや横幅を変えると左端セル幅も変わるため、専用binも合わせてください。

STL出力先は `dist/letter-case/temna-roomcase-puchi/`。
検証は `python3 tests/roomcase-puchi.py` で実行します。
