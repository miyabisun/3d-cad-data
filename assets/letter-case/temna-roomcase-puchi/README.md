# 天馬 ルームケースプチ A4-23（浅型）

[メーカー商品ページ](https://tenmafitsworld.com/SHOP/roomcase-puchi.html)の
「(2)浅」用。設計の根拠は
[台帳](../../../ledger/designs/temna-roomcase-puchi-gridfinity.md)を参照。
アイリスオーヤマ A4-LCJとは独立した製品・寸法設定です。

取得・STL生成の共通手順は[ルートのREADME](../../../README.md)を参照してください。
以下のコマンドはリポジトリのルートで実行します。

引き出しの実測値は232×323×高さ70mmです。
左右は片側0.5mm、前後は片側1mmの余裕を取り、外形を231×321×厚さ4.65mmとしています。
床なしのベースプレートです。ソケットは42mmピッチ、
嵌合の逃げは全周0.1mm。外形幅231mmの版で、引き出しへの嵌合を実物で確認済みです。
嵌合の調整は `modules/temna_roomcase_puchi.scad` で行います。
`drawer_w` / `drawer_d` / `fit_clearance` / `socket_clearance` を調整してください。
`fit_clearance` は `[左右, 前後]` の片側の余裕で、現在は `[0.5, 1]` です。

| 部品 | 外形（mm） | ソケット |
|---|---|---|
| `baseplate_front.scad` | 231×168×4.65 | 標準5列＋左半セル1列、4行 |
| `baseplate_rear.scad` | 231×153×4.65 | 標準5列＋左半セル1列、3行＋奥縁27mm |

引き出しの手前をY=0、左をXマイナスとして配置します。奥片のY=0を前片の
Y=168に突き合わせると、継ぎ目でも42mmピッチが続きます。奥側の左右角だけR5mm。
奥縁は厚さ2mmの位置決め用X筋交い付きスペーサーで、端数セルはありません。
底面Z=0をビルドプレートに置き、サポートなしで各1枚印刷します。

左端のセル幅（ピッチ）は21mm＝0.5セルです。
左端は上端開口20.7×41.7mm、垂直部16.4×37.4mm、底15×36mm。
角Rと45°の面取りは標準ソケットと同じです。
左端にはXピッチ21mmの半セルに対応したbinを使います。
既存の整数セルbinは右側5列で使用できます。
クリアランスや横幅を変えると左端セル幅も変わるため、専用binも合わせてください。

STL出力先は `dist/letter-case/temna-roomcase-puchi/`。
検証は `python3 tests/roomcase-puchi.py` で実行します。
