# アイリスオーヤマ A4-LCJ

引き出しへ敷くGridfinityベースプレート。
[設計台帳](../../../ledger/designs/letter-case-gridfinity.md)に実測・試作の経緯を記録しています。
共通値と形状は `modules/iris_oyama_a4_lcj.scad` が持ちます。

## baseplate_front.scad / baseplate_rear.scad

- 外形は合わせ込み済みの **240.6×313.5mm**、厚さ4.65mm。奥側2隅は実測に合わせてR3mm。
- セル部分は幅231mmの **5.5×7セル**。左に21mmの半セル列、右に標準5列を置きます。
  左右の縁は各4.8mmで、肉抜きせずに残します。
- 左の半セルは天馬側と同じ嵌合寸法です。上端開口20.7×41.7mm、
  垂直部16.4×37.4mm、底15×36mm。角Rと45°の面取りは標準セルと同じです。
  左列にはXピッチ21mmの半セル対応bin、右5列には既存の整数セルbinを使います。
- 前片は前縁1.5mm＋4行で奥行169.5mm。奥片は3行＋奥縁18mmで奥行144mm。
  継ぎ目を突き合わせると42mmピッチが続きます。
- 床はありません。binは引き出しの高い中央床に乗り、板は周囲のくぼみを跨ぎます。
  5.5セル版では左右端のbinの底も一部がくぼみを跨ぎます。
  半セル中心はX=-105mm、高い床の左端は実測から約-106mmです。
  アイリス側の5.5セル版では、半セルbinの座りを実機で確認してください。
- 奥縁は線幅2mmのX筋交い付き。左に19×14mm、標準列に40×14mmの窓を5つ設けています。

前片・奥片を各1枚、底面Z=0をビルドプレートに置いてサポートなしで印刷します。
STLは `dist/letter-case/iris-oyama-a4-lcj/` に出力します。
既存の3MFから印刷する場合は、新しいSTLへ差し替えてください。
検証は `./tests/letter-case.sh` で実行します。
