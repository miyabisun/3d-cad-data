# laundry

洗濯場・洗面台で使うパーツ。STL出力には[OpenSCADとこのリポジトリ](../../README.md#stlを作る)が必要です。

## bose_soundlink_flex_stand.scad

BOSE SoundLink Flexを、充電口のある左側面を下にして縦置きする充電スタンドです。
MUXER L字マグネットアダプターの機器側端子を挿したまま、上から降ろして接続します。
縦置きにしたのは、置く方向と磁気端子の着脱方向を一致させるためです。
重さは受けの床で支え、端子のケーブル側本体は床下のポケットに収めます。
上側の肩が抜け止め、ねじ留めの裏蓋が底受けです。ケーブルは後方へ水平に出します。

**一部実測済みの試作モデルです。初期値のまま実物に適合することは確認していません。**
印刷前に下表の寸法を合わせてください。必要な物はスタンドと裏蓋各1個、
MUXERアダプター、USB-Cケーブル・電源、M3×10mmの皿ねじ2本です。
ねじ頭は外径6.4mm以下・90度皿を使い、樹脂の下穴へ直接ねじ込みます。

### 寸法を合わせる

長さはmmです。左側面を下にした姿勢で、Xは元のスピーカーの上下方向（ボタン側がプラス）、
Yは前面グリルから背面方向（後方がプラス）、Zは机から上向きです。
左側面の外形中心がX=0、Y=0です。L字アダプターのケーブル口を+Yへ向けます。

| パラメーター | 初期値 | 測り方・意味 |
| --- | --- | --- |
| `speaker_side_width` / `speaker_depth` | 90 / 52 | 左端から25mmまでの最大外形。元の高さ / 前後厚み |
| `speaker_clearance` | 0.5 | 本体と受けの片側のすきま。初期の内寸は91×53 |
| `port_x` / `port_y` | 5 / 0 | 左側面の外形中心から、挿した機器側端子の吸着面中心までの符号付き距離。5mmの方向は暫定 |
| `adapter_width` / `adapter_depth` / `adapter_height` | 14.3 / 22.1 / 10.5 | ケーブル側本体の実測外形。吸着面を上にしたX幅 / Y長 / 底から抜け止めを掛ける肩までの高さに対応させる |
| `adapter_clearance` | 0.3 | ポケットの片側のすきま・上下の遊び。初期のポケットは14.9×22.7 |
| `contact_offset_y` | -5 | ケーブル側本体の外形中心から吸着面中心までのY距離。前寄りなら負 |
| `contact_width` / `contact_depth` | 8.1 / 12.6 | 実測7.5×12の機器側端子に片側0.3のすきまを加えた窓。X/Yの対応は暫定 |
| `tip_projection` | 3 | 接続した状態で、スピーカーを支える左端の面からケーブル側本体の抜け止め肩までの距離 |
| `cable_width` / `cable_height` | 12 / 8 | USB-Cプラグ・根元を含む出口の幅 / 高さ。入口の下端はケーブル側本体の底と同じ |
| `pilot_diameter` | 2.6 | M3ねじの下穴径。材質・収縮に合わせて調整 |
| `guide_height` / `wall` / `foot_margin` | 25 / 3 / 10 | 着座面からのガイド高さ / 壁厚 / 壁外側から台座端までの幅 |

初代SoundLink Flexを対象に、本体の90×52は外形約90×201×52から仮置きしています。
端子は暫定で「元の上下7.5・前後12、側面中央からボタン側へ5」と解釈しています。
軸の向きと5mmの意味は未確認です。左右を入れ替える場合は窓と保持する肩の幅も見直してください。
[MUXERの商品案内](https://item.rakuten.co.jp/cwest-cwest/10000018/)には寸法図がないため、
上表の実測外形を出発点に、接続した状態で確認します。
`contact_offset_y`、`tip_projection`、ケーブル出口の寸法は未実測です。
本体の全高10.5mmに接点の突起が含まれる場合は、`adapter_height`を実際に保持する肩の高さへ直します。

抜け止めは窓の左右に各1.5mm以上の本体の肩がある形を前提とします。
窓と接点が干渉しないこと、本体が窓から抜けないことを実物で確認してください。
肩がない形状や、後方へケーブルを向けられない個体は、このホルダーの形状変更が必要です。
机から肩までの高さは初期13.8mm、スピーカーの着座面は16.8mmです。
吸着時にケーブル側本体が最大0.3mm浮いて肩へ当たる余地を設けています。
初期外形は117×79×41.8mm、裏蓋は28.9×28.7×3mmです。

### STL出力と印刷

SCAD冒頭の寸法を変更してから、リポジトリのルートで実行します。
本体と裏蓋は必ず同じ寸法設定で出力してください。

```sh
mkdir -p dist/laundry
openscad --export-format binstl -o dist/laundry/bose_soundlink_flex_stand.stl \
  assets/laundry/bose_soundlink_flex_stand.scad
openscad --export-format binstl -D 'part="cover"' \
  -o dist/laundry/bose_soundlink_flex_cover.stl \
  assets/laundry/bose_soundlink_flex_stand.scad
```

どちらも出力時のZ=0をベッドへ置きます。裏蓋は皿穴が上向きです。
本体の底の座ぐり、端子ポケットの肩、ケーブル出口には水平の張り出しがあります。
スライサーでブリッジを確認し、必要なサポートを底から取り除いてください。
OpenSCADで`part="assembly"`を選ぶと、組立位置と半透明の概略本体を確認できます。
これは表示用で、印刷には`stand`と`cover`を個別に使います。

### 組立と調整

1. ケーブルを後方の出口から通してアダプターへ挿し、吸着面を上へ向けて底からポケットへ入れます。
2. 裏蓋を印刷時から裏返し、皿穴を机側へ向けてねじ2本で固定します。蓋とねじ頭が底面から出ないことを確認します。
3. 電源を外した状態でスピーカーを支えながら降ろし、端子へ重さを掛けず、左右の床へ着座するよう寸法を合わせます。
4. 持ち上げてもケーブル側本体が抜けないこと、台座が滑ったり倒れたりしないことを確認してから、充電を確かめます。

適合・吸着力・耐荷重・充電は実機未確認です。丸い側面でがたつく場合は受け面も調整してください。
通電確認は端子と周囲が乾いた状態で行います。

## philips_cleaning_pod_holder.scad

Philips S9696/50用のクイッククリーンポッドを、洗面台の立ち上がった棚の縁へ
上から掛ける一体型ホルダーです。下向きの溝に棚の縁を差し込み、棚の外側の受けへ
ポッドを置きます。底は幅10mmの「＋」と「×」を重ねた8方向の桟で支え、
桟の間の8つの開口から排水します。中央は塞がっています。
フック幅60mmの全体を受け外壁へつなぐ形で、接合部の隙間を埋めています。

### STL出力と印刷方向

リポジトリのルートで実行します。

```sh
mkdir -p dist/laundry
openscad --export-format binstl \
  -o dist/laundry/philips_cleaning_pod_holder.stl \
  assets/laundry/philips_cleaning_pod_holder.scad
```

SCADはOpenSCADで確認できます。STLも使用時の向きで、底面がZ=0です。
底面をベッドへ置いて印刷します。溝の天井は初期値で3.4mmのブリッジです。
溝へサポートを入れずに印刷できるかをスライサーで確認します。

### 寸法と調整

SCAD冒頭のパラメーターで調整できます。長さの単位はmmです。

| パラメーター | 初期値 | 意味 |
| --- | --- | --- |
| `pod_width` / `pod_depth` | 100 / 100 | 受ける範囲のポッド外幅・奥行き |
| `pod_corner_radius` | 50 | ポッドの角丸半径。100×100・R50で円形、R0で角形 |
| `pod_clearance` | 0.5 | ポッドの片側のすきま。初期の受け内径は101 |
| `retaining_height` | 20 | 内底から測った受け壁の高さ |
| `floor_thickness` / `wall_thickness` | 8 / 3 | 底の桟の厚さ / 受け壁厚 |
| `rib_width` | 10 | 縦横・斜めの各桟を直角方向に測った幅 |
| `edge_chamfer` | 1 | 受け・フックの外周上下の45度面取り幅（C1） |
| `shelf_thickness` / `slot_clearance` | 3 / 0.4 | 棚厚 / 溝の総補正量。初期の溝幅は3.4 |
| `slot_length` / `slot_depth` | 60 / 45 | 棚の縁に沿う長さ / 上から掛ける深さ。各60以下 / 45以下 |
| `hook_thickness` | 6 | フック両脚と天井の肉厚 |

初期外形は107×119.4×51mm、ポッドの内底は棚の縁の上端より37mm下です。
溝は下と左右へ開放しています。C1面取りは外周の幅・高さとも1mmを落とし、
溝の接触面・受け内寸・桟の幅を保ちます。

### 実物に合わせる

対象はQCP10/01です。[公式ストア](https://store.shopping.yahoo.co.jp/philips-japan/qcp10-01.html)の
外形は約135×100×100mm（高さ×幅×奥行き）、重量約348gで、S9696に対応します。
底面図は得られていないため、モデルの円形Φ100mmは仮定です。

- 棚厚はノギスで数か所測った最大値を使い、上端の丸みも通るよう溝の補正量を調整します。
  直線部の長さと上端から曲がり・棚底までの高さが差し込み寸法の上限です。
  棚の内側にはフック脚6mm分の空間も必要です。
- ポッド底から保持高さ20mmまでの最大幅・奥行き・輪郭を測り、受けの寸法へ合わせます。
  角丸半径は幅・奥行きの小さい方の半分以下です。底の脚や突起で傾く場合も調整が必要です。
  蓋・カートリッジの着脱に干渉する場合は保持高さを下げます。

実物の適合・耐荷重は未確認です。底の桟は厚さ8mm、フックは6mmですが、
片持ち荷重で棚のたわみやフックの層間剥離が起こり得ます。
液入りポッドとシェーバーを支えながら載せ、溝の開き・傾き・長時間保持・洗浄中の振動を確認してください。

## dryer_drain_adapter.scad

乾燥機の排水ホース（オス）と洗濯機の排水口（オス）を繋ぐアダプタ。
両側がメス（穴）の筒形状で、それぞれのホースを差し込んで接続する。

### 寸法

| 側 | 接続先 | ホース外径 | 穴内径 | 収縮補正 | 挿入深さ |
|----|--------|-----------|--------|---------|---------|
| A (上) | 乾燥機 | 15.2mm | 15.8mm | +0.6mm | 35mm |
| B (下) | 洗濯機 | 14.5mm | 15.5mm | +1.0mm | 35mm |

- 壁厚: 2.5mm
- 外径は大きい方の内径に合わせて統一
- A側とB側の内径差（0.3mm）が自然なストッパーとして機能する
- A側の収縮補正は実測フィードバックにより1.0→0.6mmに調整済み
