# laundry

洗濯場・洗面台で使うパーツ。STL出力には[OpenSCADとこのリポジトリ](../../README.md#stlを作る)が必要です。

## bose_soundlink_flex_stand.scad

初代BOSE SoundLink Flexの充電口がある左側面を下にし、縦置きする充電スタンドです。
USB-CのL字マグネットアダプターを使い、置く方向と端子の着脱方向を揃えます。
前面の浅い丸み・背面の大きな丸み・左端の丸みに沿う受けを持ち、前面の壁を低くしています。
台座も同じ輪郭で裾を広げています。端子は床下のポケットに収め、上の肩とねじ留めの裏蓋で保持します。

**写真から輪郭を近似した試作です。**
寸法図・メーカーCADに基づく形状ではなく、実機への適合は未確認です。

[初代の公式仕様](https://www.bose.com/p/speakers/bose-soundlink-flex-bluetooth-speaker/SLFLX-SPEAKERWIRELESS.html)の
3.56×7.93×2.06インチを約90.4×201.4×52.3mmとして使用しました。
前後の非対称とUSB-Cの長軸方向は[公式の左側面写真](https://assets.bosecreative.com/transform/83659360-be66-42a5-8861-3af7f9b944c1/flex_white_smoke_side)を参照しています。
曲率・端の丸み・端子位置には寸法の根拠が不足しているため、以下を実物に合わせて調整してください。

### 寸法と未確定箇所

単位はmmです。左側面を下にして、Xは元の上下方向（ボタン側がプラス）、
Yはグリルから背面へ（後方がプラス）、Zは机から上へ向けます。X/Yの原点は外形中心です。

| パラメーター | 初期値 | 根拠・調整箇所 |
| --- | --- | --- |
| `speaker_side_width` / `speaker_depth` | 90.4 / 52.3 | 公式の全体寸法。左端から25mmまでの最大外形を実測して調整 |
| `front_radius` / `back_radius` / `end_radius` | 5 / 22 / 6 | 写真からの近似。前面角 / 背面角 / 左端の丸み。実測した半径ではない |
| `speaker_clearance` | 1 | 本体と受けの片側のすきま。最大内寸は92.4×54.3。底では端の丸みに合わせて狭まる |
| `port_x` / `port_y` | 5 / 0 | 端子の吸着面中心。位置は未確定。ボタン側へ5・前後0の仮置き |
| `adapter_width` / `adapter_depth` / `adapter_height` | 14.3 / 22.1 / 10.5 | ケーブル側本体の実測値。吸着面を上にしたX / Y / 保持する肩までのZへ対応させる |
| `contact_width` / `contact_depth` | 12.6 / 8.1 | 機器側端子の実測12×7.5＋片側0.3。写真のUSB-C長軸に合わせて12をXへ配置。アダプター側でも確認する |
| `contact_offset_y` / `tip_projection` | -5 / 3 | 未測定。本体中心から吸着面中心へのY距離 / スピーカーの着座面からケーブル側本体の肩までの距離 |
| `cable_width` / `cable_height` | 12 / 8 | 未測定。USB-Cプラグ・根元を含む後方出口の幅 / 高さ |
| `guide_height` / `front_height` | 25 / 8 | 着座面からの背面・側面ガイド / 前面の縁の高さ |
| `wall` / `foot_margin` / `pilot_diameter` | 3 / 10 / 2.6 | 壁厚 / 台座の裾の張り出し / M3ねじの下穴径 |

ポケットには片側・上側に`adapter_clearance=0.3`の遊びがあります。
本体の10.5に接点の突起が含まれている場合、`adapter_height`は保持する肩までの高さに直します。
初期の端子窓は左右に各0.85mm、前後に各1.5mm以上の本体の肩が残る前提です。
アダプターの形がこの保持方法に合うことと、ケーブルを+Yへ出せることを確認します。
初期外形は約118.4×80.3×41.8mm、着座面は机から16.8mm、裏蓋は28.9×28.7×3mmです。

### 出力・印刷・組立

必要な物は本体・裏蓋各1個、アダプター、USB-Cケーブル・電源、M3×10mm皿ねじ2本です。
ねじは頭の外径6.4mm以下・90度皿を使います。寸法を変更した場合、本体と裏蓋は同じ設定で出力します。

```sh
mkdir -p dist/laundry
openscad -o dist/laundry/bose_soundlink_flex_stand.3mf \
  assets/laundry/bose_soundlink_flex_stand.scad
openscad -D 'part="cover"' -o dist/laundry/bose_soundlink_flex_cover.3mf \
  assets/laundry/bose_soundlink_flex_stand.scad
```

STLが必要な場合は出力先の拡張子を`.stl`にします。どちらもZ=0をベッドへ置きます。
裏蓋は皿穴が上向きです。本体の座ぐり・端子ポケット・ケーブル出口のブリッジをスライサーで確認し、
必要なサポートは組立前に底から除去します。
OpenSCADの`part="assembly"`は、写真から近似した半透明のスピーカーと組立位置の確認用です。

1. ケーブルを後方から通してアダプターへ挿し、吸着面を上へ向けて底からポケットへ入れます。
2. 裏蓋を裏返し、皿穴を机側にしてねじ2本で固定します。蓋とねじ頭を底面から突出させません。
3. 電源を外してスピーカーを支えながら降ろし、丸みの干渉やがたつきを確認します。
   床で重さを支え、端子を押し込まずに吸着するよう、曲率・端子位置・高さを合わせます。
4. 持ち上げてもケーブル側本体が抜けず、台座が倒れないことを確認してから、乾いた状態で充電を確認します。

形状テストは曲面・開口・保持部・閉じたメッシュを検査します。実物の適合・吸着力・耐荷重・充電は別途確認が必要です。

## philips_cleaning_pod_holder.scad

Philips S9696/50用のクイッククリーンポッドを、洗面台の立ち上がった棚の縁へ
上から掛ける一体型ホルダーです。下向きの溝に棚の縁を差し込み、棚の外側の受けへ
ポッドを置きます。底は幅10mmの「＋」と「×」を重ねた8方向の桟で支え、
桟の間の8つの開口から排水します。中央は塞がっています。
フック幅60mmの全体を受け外壁へつなぐ形で、接合部の隙間を埋めています。

### STL出力と印刷方向

リポジトリのルートで実行します。

```sh
mkdir -p dist/laundry
openscad --export-format binstl \
  -o dist/laundry/philips_cleaning_pod_holder.stl \
  assets/laundry/philips_cleaning_pod_holder.scad
```

SCADはOpenSCADで確認できます。STLも使用時の向きで、底面がZ=0です。
底面をベッドへ置いて印刷します。溝の天井は初期値で3.4mmのブリッジです。
溝へサポートを入れずに印刷できるかをスライサーで確認します。

### 寸法と調整

SCAD冒頭のパラメーターで調整できます。長さの単位はmmです。

| パラメーター | 初期値 | 意味 |
| --- | --- | --- |
| `pod_width` / `pod_depth` | 100 / 100 | 受ける範囲のポッド外幅・奥行き |
| `pod_corner_radius` | 50 | ポッドの角丸半径。100×100・R50で円形、R0で角形 |
| `pod_clearance` | 0.5 | ポッドの片側のすきま。初期の受け内径は101 |
| `retaining_height` | 20 | 内底から測った受け壁の高さ |
| `floor_thickness` / `wall_thickness` | 8 / 3 | 底の桟の厚さ / 受け壁厚 |
| `rib_width` | 10 | 縦横・斜めの各桟を直角方向に測った幅 |
| `edge_chamfer` | 1 | 受け・フックの外周上下の45度面取り幅（C1） |
| `shelf_thickness` / `slot_clearance` | 3 / 0.4 | 棚厚 / 溝の総補正量。初期の溝幅は3.4 |
| `slot_length` / `slot_depth` | 60 / 45 | 棚の縁に沿う長さ / 上から掛ける深さ。各60以下 / 45以下 |
| `hook_thickness` | 6 | フック両脚と天井の肉厚 |

初期外形は107×119.4×51mm、ポッドの内底は棚の縁の上端より37mm下です。
溝は下と左右へ開放しています。C1面取りは外周の幅・高さとも1mmを落とし、
溝の接触面・受け内寸・桟の幅を保ちます。

### 実物に合わせる

対象はQCP10/01です。[公式ストア](https://store.shopping.yahoo.co.jp/philips-japan/qcp10-01.html)の
外形は約135×100×100mm（高さ×幅×奥行き）、重量約348gで、S9696に対応します。
底面図は得られていないため、モデルの円形Φ100mmは仮定です。

- 棚厚はノギスで数か所測った最大値を使い、上端の丸みも通るよう溝の補正量を調整します。
  直線部の長さと上端から曲がり・棚底までの高さが差し込み寸法の上限です。
  棚の内側にはフック脚6mm分の空間も必要です。
- ポッド底から保持高さ20mmまでの最大幅・奥行き・輪郭を測り、受けの寸法へ合わせます。
  角丸半径は幅・奥行きの小さい方の半分以下です。底の脚や突起で傾く場合も調整が必要です。
  蓋・カートリッジの着脱に干渉する場合は保持高さを下げます。

実物の適合・耐荷重は未確認です。底の桟は厚さ8mm、フックは6mmですが、
片持ち荷重で棚のたわみやフックの層間剥離が起こり得ます。
液入りポッドとシェーバーを支えながら載せ、溝の開き・傾き・長時間保持・洗浄中の振動を確認してください。

## dryer_drain_adapter.scad

乾燥機の排水ホース（オス）と洗濯機の排水口（オス）を繋ぐアダプタ。
両側がメス（穴）の筒形状で、それぞれのホースを差し込んで接続する。

### 寸法

| 側 | 接続先 | ホース外径 | 穴内径 | 収縮補正 | 挿入深さ |
|----|--------|-----------|--------|---------|---------|
| A (上) | 乾燥機 | 15.2mm | 15.8mm | +0.6mm | 35mm |
| B (下) | 洗濯機 | 14.5mm | 15.5mm | +1.0mm | 35mm |

- 壁厚: 2.5mm
- 外径は大きい方の内径に合わせて統一
- A側とB側の内径差（0.3mm）が自然なストッパーとして機能する
- A側の収縮補正は実測フィードバックにより1.0→0.6mmに調整済み
