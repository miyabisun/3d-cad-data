# laundry

洗濯場・洗面台で使うパーツ。STL出力には[OpenSCADとこのリポジトリ](../../README.md#stlを作る)が必要です。

## philips_cleaning_pod_holder.scad

Philips S9696/50用のクイッククリーンポッドを、洗面台の立ち上がった棚の縁へ
上から掛ける一体型ホルダーです。下向きの溝に棚の縁を差し込み、棚の外側の受けへ
ポッドを置きます。底に直径8mmの排水穴があります。

対象はQCP10/01です。[Philips公式ストアの商品仕様](https://store.shopping.yahoo.co.jp/philips-japan/qcp10-01.html)には
外形約135×100×100mm（高さ×幅×奥行き）、重量約348g、S9696対応と記載されています。
この外形から底面の輪郭やテーパーは確定できません。モデルの初期値は直径100mmの
円形を仮定しており、実物との適合・荷重を掛けた保持は未確認です。

### 寸法と調整

SCAD冒頭のパラメーターで調整できます。長さの単位はmmです。

| パラメーター | 初期値 | 意味 |
| --- | --- | --- |
| `pod_width` / `pod_depth` | 100 / 100 | 受ける範囲のポッド外幅・奥行き |
| `pod_corner_radius` | 50 | ポッドの角丸半径。100×100・R50で円形、R0で角形 |
| `pod_clearance` | 0.5 | ポッドの片側のすきま。初期の受け内径は101 |
| `retaining_height` | 20 | 内底から測った受け壁の高さ |
| `floor_thickness` / `wall_thickness` | 8 / 3 | 底厚 / 受け壁厚 |
| `drain_diameter` | 8 | 底の排水穴径 |
| `shelf_thickness` / `slot_clearance` | 3 / 0.4 | 棚厚 / 溝の総補正量。初期の溝幅は3.4 |
| `slot_length` / `slot_depth` | 60 / 45 | 棚の縁に沿う長さ / 上から掛ける深さ。各60以下 / 45以下 |
| `hook_thickness` | 6 | フック両脚と天井の肉厚 |

初期外形は幅107×奥行き119.4×高さ51mmです。溝は下と左右に開いており、
幅60mmのフックの両側へ棚の縁が続いていても差し込めます。ポッドの内底は棚の縁の
上端より37mm下になります。角丸半径はポッドの幅・奥行きの小さい方の半分以下にします。

実物に合わせるときは、次を測ります。

- 棚の縁の厚さをノギスで数か所測り、最大値を`shelf_thickness`へ入れます。
  厚みの変化や上端の丸みも含め、印刷後の溝が無理なく通るよう`slot_clearance`を調整します。
- 棚の縁の直線部分の長さと、上端から曲がり・棚底までの差し込み可能な高さを測り、
  `slot_length`と`slot_depth`をその範囲内へ合わせます。棚の内側にフック脚6mm分の空間も必要です。
- ポッドを平面に置き、底面から20mmまでの幅・奥行きの最大値と角の輪郭を測ります。
  テーパーがあればその最大外形に合わせ、底の脚や突起で傾かないことも確認します。
  円形でなければ幅・奥行き・角丸半径を変更します。
- 蓋・カートリッジの着脱位置と、シェーバーを載せた状態の周囲の空間を確認し、
  受け壁が干渉する場合は`retaining_height`を調整します。

### STL出力と印刷方向

リポジトリのルートで実行します。

```sh
mkdir -p dist/laundry
openscad --export-format binstl \
  -o dist/laundry/philips_cleaning_pod_holder.stl \
  assets/laundry/philips_cleaning_pod_holder.scad
```

SCADをOpenSCADで開くと使用時の向きで表示されます。STLも同じ向きで、底面がZ=0です。
初回は底面をベッドへ置いて印刷します。溝の天井は3.4mmのブリッジになり、
溝へサポートを入れずに印刷できるかをスライサーで確認します。補正量を変えるとこの幅も変わります。

片持ち荷重は厚さ8mmの底から厚さ6mmのフックへ伝わります。この印刷方向では
フックに層間剥離の負荷が掛かるため、肉厚だけで耐荷重は保証できません。
液入りポッドとシェーバーを合わせた実重量で、棚のたわみ・溝の開き・ホルダーの傾きを
落下しないよう支えながら確認してください。長時間の保持と洗浄中の振動も確認対象です。

## dryer_drain_adapter.scad

乾燥機の排水ホース（オス）と洗濯機の排水口（オス）を繋ぐアダプタ。
両側がメス（穴）の筒形状で、それぞれのホースを差し込んで接続する。

### 寸法

| 側 | 接続先 | ホース外径 | 穴内径 | 収縮補正 | 挿入深さ |
|----|--------|-----------|--------|---------|---------|
| A (上) | 乾燥機 | 15.2mm | 15.8mm | +0.6mm | 35mm |
| B (下) | 洗濯機 | 14.5mm | 15.5mm | +1.0mm | 35mm |

- 壁厚: 2.5mm
- 外径は大きい方の内径に合わせて統一
- A側とB側の内径差（0.3mm）が自然なストッパーとして機能する
- A側の収縮補正は実測フィードバックにより1.0→0.6mmに調整済み
