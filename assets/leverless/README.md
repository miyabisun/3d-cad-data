# 左右の指配置を分けたレバーレス筐体

[controller.scad](controller.scad) をOpenSCADで開く。初期表示は組立状態。
`part` を変更すると、各部品を印刷する向きで表示・出力できる。
`frame`では天底板を外した内部構造を確認できる。
組立外寸は約400 × 200 × 61mm。**assemblyとframeは確認用で、印刷しない。**
印刷部品はすべてP1Sの256mm角に収まる。

## 印刷する部品

| part | 数 | 外寸の基準 (mm) |
|---|---:|---|
| `top_left` / `top_right` | 各1 | 200 × 200 × 6 |
| `bottom` | 2 | 200 × 200 × 5 |
| `corner_post` / `corner_post_right` | 各2 | 40 × 40 × 50、腕厚20のL字 |
| `center_post` | 2 | 80 × 20 × 50、中央の壁と左右の受けを一体化 |
| `corner_nut_plug` | 8 | 幅6.9 × 差込方向14.9898 × 高さ3.1、左右隅柱共通 |
| `center_nut_plug` | 8 | 幅6.9 × 差込方向6.9585 × 高さ3.1、中央柱用 |
| `wall` | 6 | 長さ160 × 高さ50 × 厚さ5、全周共通 |

壁は6枚とも同じ形状。端面に片側0.25mmの逃げがあり、実長は159.5mm。
端まで高さ50mmの長方形で、上下のタブや45度の肩はない。
側壁は外面を下に、天底板は外面を上にした出力姿勢。
柱は立てて印刷する。ナット溝の屋根は幅7.3mmのブリッジになる。
丸穴と重なる所は、横長7.3×4.4の開口を0.4mm、続いて4.4角の開口を
もう0.4mm上げた二段構造。斜めの四角と丸穴の接線で微小な面が生まれるのを避けるため、
橋渡し部分の4.4mmには片側1/64mmずつの逃げを足す（4.43125mm）。
ネジ本体の通し穴φ4.4は維持する。底用ナットも印刷時の上側に足場を作る。
隅柱の上下ナットはL字の内隅から斜め45度に差し込む。
この45度は平面上の通路の向きで、壁の高さ方向に斜面はない。
中央部品の上下ナットはケース内面から直線で差し込む。
上下ナットのスリットは別体の栓で塞ぐ。栓は高さ3.1mmのまま平置きで印刷する。

```sh
mkdir -p dist/leverless
openscad --export-format binstl -o dist/leverless/corner_post.stl -D 'part="corner_post"' assets/leverless/controller.scad
openscad --export-format binstl -o dist/leverless/top_right.stl -D 'part="top_right"' assets/leverless/controller.scad
openscad --export-format binstl -o dist/leverless/corner_nut_plug.stl -D 'part="corner_nut_plug"' assets/leverless/controller.scad
openscad --export-format binstl -o dist/leverless/center_nut_plug.stl -D 'part="center_nut_plug"' assets/leverless/controller.scad
```

STLはバイナリ形式を使う。OpenSCAD 2021.01のASCII出力では、丸みと皿穴の
細かい面で座標が丸められ、再読込時にCGALエラーを確認した。通常の`bin/render`
は形式を指定しないため、このモデルの印刷には上記コマンドで出力する。

隅柱は外周のR3を外へ、ナット入口をL字の内隅へ向けて配置する。
中央部品は前後それぞれ中央に置く。左右160mm壁と中央部品の一体の壁40mmが
外周を埋め、同じ壁6枚で400×200mmの枠になる（受けへの重なりを含む）。

## 締結と組立

- 各200mm板の四隅から10mmの位置にM4通し穴φ4.4。皿座は仮に径9.4・90度。
  全皿座は外面から深さ0.4mmの円柱を掘り、その下にテーパを設ける。
- 柱の上下端から5mmの樹脂を残し、その内側に高さ3.5・幅7.3mmのナット溝。
  穴付近だけ二段の橋渡し用に最大0.8mmを追加で逃がす（残り4.2mm）。
  ケース内側からM4六角ナットを横差しし、ネジを通して保持する。
  柱のM4縦穴はφ4.4を全高50mmに貫通させ、上下の止まり穴の間に天井を作らない。
  ナット溝の二段ブリッジは保持する。
  隅柱の腕の端にあった長い入口は廃止した。
- 上下ナットをネジで所定位置に保持し、栓の短辺側を先にスリットへ入れる。
  断面は幅7.3 × 高さ3.5mmの溝からそれぞれ合計0.4mm小さくし、片側0.2mmの逃げを設ける。
  二面幅7mmの六角ナット先端に当たった位置で、内側の入口面から差込方向へ1mm突出する。
  長さはナット中心から入口までの距離（隅柱は25.5/√2、中央柱は10mm）から
  ナットの外接半径7/√3を引き、突出1mmを加えた値。
  突出部分をはんだごてで溶かして入口に固定する。実ナットの寸法や回転の遊びで
  突出量は変わるため、溶かす前に位置を確認する。実寸調整はSCADの`plug_nut_flat`、
  嵌合の調整は`plug_clearance`、突出量は`plug_protrusion`で行う。
  上下共通で隅用8個・中央用8個。側壁用の六角ナット穴には使わない。
  組立表示にはネジ・ナット・栓を含めず、栓は各`part`で単体表示する。
- 側壁用ナットは柱の内面に開いた二面幅7.3・深さ3.5mmの六角穴へ入れる。
  側壁用の通し穴は柱・壁とも二面幅4.4mmの上辺が水平な六角形。
  ナット穴も二面幅7.3mmで上辺を水平にし、天井をブリッジで印刷する。
  高さはすべて柱底から25mm。隅柱の直交する穴は別々の腕の中心へ配置する。
- 壁端の20mmを、深さ5mm・高さ50mmの欠き込みへ重ねる。
  隅柱が外周のR3を受け持ち、壁は角から20mm
  離れた平面で接続する。留め継ぎは使わない。
  ナット入口のあるL字内隅はC5.5の45度面取り（平面幅約7.78mm）とし、
  幅7.3mmの入口全体の上辺を直線にする。外周側の角はR3を維持する。
  内部へ突き出す腕の先端2箇所も、縦の稜線を全高にわたりR3で丸める。
- 中央前後の部品は幅80mmで、両端20mmずつが壁受け、中央40mmが外周壁になる。
  上下ネジは全体X=190/210mmを維持し、左右の天板・底板それぞれへ締結する。
  横ネジは全体X=170/230mmへ移す。ケース内部を横断する仕切り壁はなく、
  内部の幅350 × 奥行150mmの領域を配線に使える。
  中央部品も内部側の両端2箇所の縦の稜線をR3にする。壁の受け面は平面を保つ。

M4六角ナットは合計28個（上下16・側壁12）。一般的な二面幅7・厚さ3.2mmを想定。
ネジ長の候補は天底用M4×16を16本、側壁用M4×25を12本。側壁ネジは内面から
約5mm出る。皿頭の径・角度は購入したネジで確認する。

1. ナットの嵌合、ブリッジの垂れを隅柱1本で確認する。
2. 柱にナットを入れ、前後壁と左右壁を仮締めして枠を作る。
3. 底板2枚を留める。外周の丸みが外を向き、中央は平らな端面同士で合う。
4. ボタンと基板を天板へ取り付け、左右の配線を通す。天板を留めて本締めする。
5. 滑り止めパッドを貼る前に、中央の曲げ・ねじれ・締結部の緩みを現物で確認する。

PLA+のねじ込みを締結に使わない。実物の耐荷重・繰り返し使用の強度は未検証。

## 天板と底板

PWS Blaze用の穴はφ24.4、右手小指の大ボタンだけφ30.4。
ボタンの縁はそれぞれφ27 / φ33。基準配列は24mm同士の中心距離27mm、
24mmと30mmは30mmとし、三角関数と2円の交点から計算する。
下表のとおり、変更しない隣接関係では公称の縁同士の余白は0mm。
固定ナットの外寸は別途実物で確認する。

- 基準配列は[Vewlix寸法図](https://www.slagcoin.com/joystick/layout/vewlix.png)の
  上段の比率33:14を27mmピッチへ正規化した派生配置。純正の上下段の横ずれは省略し、
  30mmボタンは基準配列の強P/Kの高さ中央、下の24mmは強Kから27mm・大ボタンから30mmに置く。
- 全体20度の回転は取り消した。弱Pは弱K、中Pは中Kを中心に、半径27mmの円弧上を
  反時計回りへそれぞれ16mm・6mm移動する。回転角へ換算すると約33.953度・12.732度。
  `punch_arc`が円弧長、`thumb_angle`が親指の角度、`center_shift`が中央への移動量。
  全体の左右余白を揃えた基準配列から右を中央へ10mm移し、変更後の再中央寄せはしない。
- 右のジャンプ・パリィは弱Kを軸に30度回す。
  弱K→ジャンプ→パリィの中心距離はそれぞれ27mm。
  右向き+Xを0度とした方向は-105度で、南南西へ並ぶ。
  左は修正後の右の強P・中P・弱P・ジャンプ・パリィを鏡像にし、左も10mm中央へ寄る。
- 補助ボタンは既存の右3個を置換し、左右2個ずつの計4個。
  中心は右(24.5,160.5)/(53.5,160.5)、左(175.5,160.5)/(146.5,160.5)。
  f2ash-tap向けに中心間29mm、穴径φ24.4、外装φ29として検査する。
  中央から中心10mmでは左右の外装が重なるため、中央から縁まで10mmとした。
  中央柱の手前端Y=180から外装の奥端まで5mm空ける。

| ボタンの組 | 中心距離 (mm) | 公称の縁の隙間 (mm) |
|---|---:|---:|
| 弱P－中P | 36.943 | 9.943 |
| 中P－強P | 32.957 | 5.957 |
| 弱P－弱K / 中P－中K / 強P－強K | 27 | 0 |
| 弱K－ジャンプ / ジャンプ－パリィ | 27 | 0 |
| 30mm－強P・強K・右下24mm | 30 | 0 |
| 補助ボタン同士 | 29 | 0 |
| 弱Pに近い補助－弱P（左は鏡像） | 30.650 | 2.650 |

原点は各200mm天板の左手前、Xは右、Yは奥。`buttons_left/right`が穴中心の正本。
`part="button_layout"`のSVG出力で穴の平面図と、echoで計算後の座標を取得できる。

天板厚は6mm。手のひら用の凹みは削除し、ボタン穴とネジ穴以外は平面とした。
露出する上面外周にR3を付け、中央の接合辺は丸めない。

BrookのABXY配線を近づけるため、右天板の手前へ公開PicoFightingBoard v1.1aの4穴を使ったM3皿ネジ穴を設ける。
基板は長辺が左右方向、部品面はケース内側、USB端子は右向き。
KiCadの部品面表示を長辺軸で裏返した穴位置を、天板外面から見た座標で表す。
**BOOTHのType-C改造版と同寸かは未確認のため、基板穴は公開元寸法による暫定値。**
[基板の寸法・取付方法・安価な候補](pcb.md)に、元CADの座標と確認範囲を記載した。
M3穴はφ3.4、皿座はφ6.4・90度で外面から深さ0.4mmの円柱を先に掘る。
外面から皿ネジを入れ、天板裏のM3ナットで浮かせ、基板をもう1個のナットで挟む。
`pcb_mounts_left/right`へ別の穴中心配列を渡すと置換でき、`[]`なら基板穴なし。

底板には167 × 77 × 深さ1mmの窪みを各2個設けてある。
Paradise Arcade Nonslip FightStick Padを切らずに横向きで計4枚貼る想定。
窪みの下には4mmの板厚を残す。底の外周にもR3を付ける。

## 検証

`python3 tests/leverless.py`で出力STLの外寸・閉曲面・連結性、ナット溝の
L字内隅からの挿入経路と二段ブリッジ、上辺が水平な六角横穴、0.4mmの皿座、ボタン穴・中心間距離・縁の
非干渉、弱P/中Pの円弧移動・親指30度・左右5穴の鏡像、29mmピッチの補助ボタンと柱・壁の非干渉、右基板穴・外形とUSB予約枠、M3の皿座、
内部側のR3、M4縦穴の全高貫通、平らな掌部、パッド窪み、中央配線空間と組立部品の非干渉を測定する。
設計の根拠と未確定事項は[設計台帳](../../ledger/designs/leverless-controller.md)を参照。
