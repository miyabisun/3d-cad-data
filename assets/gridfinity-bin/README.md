# gridfinity-bin

Gridfinity の bin (箱)。レターケースのベースプレート (`assets/letter-case`) に
並べて使う。設計思想は `ledger/designs/gridfinity-bin-4u.md` が正本。
共通値は `modules/gridfinity_bin_4u.scad`、形状は `modules/gridfinity_bin.scad`。

## bin_{c}x{r}x4u.scad (25 種)

cols 1..5 × rows 1..5 の高さ 4U。cols が横 (X)、rows がラベルの壁から奥 (Y)。
各 asset は `gridfinity_bin(cols, rows, units)` の 1 呼び出し。どれも底面を
ビルドプレートへ置き、サポート不要 (面取り・くさびは 45°)。

- 外形は c×42−0.5 × r×42−0.5 (1×1 は 41.5 角、5×5 は 209.5 角)、角 R3.75。壁の上端 z=28、リップ 4.4 で全高 32.4
- 底は Gridfinity 公称の 3 段 (35.6 → 37.2 → 41.5、高さ 4.75) で穴なし (無垢)
- 壁 1.2、床 1.2 (床の天面 z=5.95)
- 薄いリップ: 壁がそのまま立ち、内側の上端 0.8 を 45° に落とすだけ。内側に棚は無い
- ラベル天板: 手前 (y=0) の壁の上端と面一で内側へ 13mm 張り出す厚さ 1 の板。
  12mm 幅のラベルシール用。下は 45° の無垢のくさびが壁まで下りる (ブリッジ無し。
  中身はスライサのインフィル任せ)。天板の先端と 45° 面の境目は R1

## card_case_2x3x4u.scad

プラスチックカード (実測 53.7×85.5×0.8) を寝かせて入れるケース。外形・底・薄いリップは
`bin_2x3x4u` と同じで、ラベル天板は無い。`gridfinity_card_case(2, 3, 4)` の 1 呼び出し。

- 内側は床の天面 (z=5.95) から壁の上端 (z=28) まで無垢 (スライサのインフィル任せ)
- 中央 (0, 62.75) にカードより 1mm 大きいポケット 54.7 (X) × 86.5 (Y)。長辺を Y (奥行き)
  に寝かせる (2 マスの内幅 81.1 に 85.5 は入らない)。平面の隅 R4。斜めに入れてパタッと落ちる
- ポケットの中心に指穴 20 (X) × 30 (Y)、隅 R4。床と底を貫通して z=0 まで抜けるので、
  ベースプレートに載せたとき指が床より下 (ソケットの底) まで届き、最後の 1 枚を掬える。
  縦 30 は手前から斜めに入る指のぶん
- 容量は壁の上端まで約 27 枚 (0.8 厚)、リップの上端 (32.4) まで約 33 枚
