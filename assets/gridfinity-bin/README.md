# gridfinity-bin

レターケースのGridfinityベースプレートに並べるbin。設計の経緯は
[設計台帳](../../ledger/designs/gridfinity-bin-4u.md)、共通値は
[gridfinity_bins.scad](../../modules/gridfinity_bins.scad)、形状は
[gridfinity_bin.scad](../../modules/gridfinity_bin.scad)が持つ。

## 高さ別の通常bin（各33種、計66種）

STLは`dist/gridfinity-bin/`に、同じ構造の編集用SCADはこのディレクトリに置く。
ファイル名は`XxY`だけにし、高さは親ディレクトリで選ぶ。

```text
gridfinity-bin/
├── 4u/1x2.stl
├── 9u/1x2.stl
└── goods/card_case_2x3x4u.stl
```

- X（横）: **1、1.5、2、2.5、3**
- Y（手前から奥）: **1、2、3、4、5、5.5、6**
- **両軸に0.5が付く1.5×5.5・2.5×5.5は作らない。** 各高さで35−2＝33種類。
- 4Uは壁の上端28mm＋リップ4.4mm＝全高32.4mm。
- 9Uは壁の上端63mm＋リップ4.4mm＝全高67.4mm。天馬の有効高さ70mmなら余裕2.6mm。

各assetは`gridfinity_bin(cols, rows, units)`の1呼び出し。外形は
X×42−0.5 × Y×42−0.5mm、最大の3×6は125.5×251.5mm。外周はR3.75。
旧`bin_*x4u.stl`は高さ別の構成へ置き換える。

### 半セルと横向きの使い方

端数はXの左端・Yの手前に21mm幅の足を1個置き、残りは42mmピッチにする。
足の角R・高さ・面取り角度は標準セルと同じで、幅だけ21mm短くする。
全サイズでラベルは奥側（＋Y）に置き、手前から物を出し入れする空間を確保する。
Xが1.5/2.5のbinは、左半セルをレターケースの左端の半セルへ合わせる。
Yが5.5のbinは**上から時計回りに90度回転**させると、半セルが左側、ラベルが右側になる。
グリッド幅231mmに対するbinの実幅は230.5mm。

### 共通形状・印刷

- 底はGridfinity公称の3段（35.6 → 37.2 → 41.5、高さ4.75）で磁石穴・ネジ穴なし。
- 壁1.2、床1.2mm（床の天面z=5.95）。
- 薄いリップは壁を4.4mm伸ばし、内側の上端0.8mmを45度に落とす。内側に棚を持たない。
- ラベル天板はすべて奥側（＋Y）に置く。
  壁の上端と面一で内側へ13mm張り出す、厚さ1mmの板。
  下は45度の無垢のくさび、先端と斜面の境目はR1。12mm幅のラベルシール用。
- 底面をビルドプレートに置き、サポートなしで印刷する。中身はスライサのインフィルで調整する。
- 新しい半セルbinと9Uの実機での嵌合・引き出し開閉は未確認。

`python3 tests/gridfinity-bin-matrix.py`は66種のSTL寸法・足・閉曲面を検査する。
5.5セル版は回転後の足を天馬のソケットと照合する（輪郭差の許容0.01mm）。ラベルのRやカードの詳細断面は
`./tests/gridfinity-bin.sh`が検査する。両方とも`npm test`に含まれる。

## goods/card_case_2x3x4u.scad

プラスチックカード (ISO/IEC 7810 ID-1: 85.6×54×0.76、隅 R3) を寝かせて入れるケース。外形・底・薄いリップは
`4u/2x3` と同じで、ラベル天板は無い。`gridfinity_card_case(2, 3, 4)` の 1 呼び出し。

- 内側は床の天面 (z=5.95) から壁の上端 (z=28) まで無垢 (スライサのインフィル任せ)
- ポケット: カードより 1mm 大きい 55 (X) × 86.6 (Y)、隅 R3 (カードの隅と同じ。R4 だと隅で突っ掛かる)。
  X は中央、手前の壁の内面から 10 奥 (x −27.5..27.5、y 11.2..97.8)。長辺は Y (2 マスの内幅 81.1 に
  85.6 は入らない)。斜めに入れてパタッと落ちる。床は bin の床 (z=5.95)。壁は上端まで垂直
- ラベル帯: ポケットの左右の埋めの天面 (z=28) は幅 13.05 の平面で、12mm 幅のラベルシールを貼れる
- 右奥のマスの穴: 埋めを壁の内面まで抜く (x 0.25..40.55、y 84..124.3、隅は内壁と同じ R2.55)。
  床と底のマスを外形の3段に平行な45°の窪みにする。
  断面は39.1角 @ z=5.95 → 34.8角 @ 3.8 → 垂直 → 床z=2.95。
  床の天面から3.0mm下がり、貫通しない。
  カードの右奥の角 (x 0.25..27.0、y 84..97.3、約27×13) がこの穴の上に張り出す。
  下の空間へ指を入れて角を掬い、底に張り付いた最後の1枚を引き上げる。
- 交点の縦エッジ: ポケットと穴が交わる所の凸の縦エッジ2本をR2で丸める (抜く輪郭の閉演算)。
  対象はポケットの右の辺×穴の手前の辺、穴の左の辺×ポケットの奥の辺。指が痛くないため。
  開口の上縁は丸めない (収まる枚数を減らさない)
- 容量は壁の上端まで約 29 枚 (0.76 厚)、リップの上端 (32.4) まで約 34 枚
