# 天馬用ケーブルホルダー

ルームケースプチの5.5マス幅に合わせた9Uのbinと、差し替え式のU字仕切り板です。
前後の縦溝へ板を上から差し込み、ケーブルの太さに合わせて区画を広げられます。

取得とSTL生成は[ルートREADME](../../../../README.md)を参照してください。
STLの出力先は `dist/gridfinity-bin/goods/cable-holder/` です。

| SCAD / STL名 | 印刷時の外形（mm） | 用途 |
|---|---|---|
| `3x5.5x9u` | 230.5×125.5×67.4 | 奥行3マスの本体 |
| `4x5.5x9u` | 230.5×167.5×67.4 | 奥行4マスの本体 |
| `divider_3` | 122.7×57.05×2 | 3マス用の仕切り板 |
| `divider_4` | 164.7×57.05×2 | 4マス用の仕切り板 |

本体はファイル名のサイズを横向きにした状態で出力します。
Xが幅5.5マス、Yが奥行3または4マス。半セルは左側です。
底面Z=0を下にして印刷し、天馬のベースプレートの左半セルへ合わせます。
本体と仕切り板はそれぞれ出力時の向きで、サポートなしで印刷できます。
仕切り板は平置きの単品です。必要な奥行き用の板をスライサで10枚などに複製してください。

## 区画の幅

- 取り付け位置は10mmピッチで前後に22組。板は厚さ2mmです。
- 全位置へ入れると23区画。中間の内幅は8mm、左右端は各8.05mmです。
- 位置を1つ飛ばすと約18mm、2つ飛ばすと約28mmになります。
- 板10枚なら最大11区画を作れます。幅は板を溝の中央に置いた場合の公称値です。

仕切りの上縁はなだらかなU字で、中央高さは約39.94mm（全高57.05mmの70%）です。
外形の四隅は直角です。差し込み溝と床の接続部にもRはありません。
左右の窓を10mm幅の十字桟で分け、4列×2段の8つの貫通窓にしています。窓の角はR2です。
小窓の横幅は3マス用で最大18.18mm、4マス用で28.68mm、高さはいずれも20mm未満です。
上縁・底・中央の柱・差し込み側の端には10mmの幅を残します。
組立時はbinの床Z=5.95mmに板が載り、脚の上端はZ=63mmになります。
本体はラベル棚を持たず、横の収納幅を確保します。

窓は同じ外形の穴なし板から体積を約21%（3マス用）／25%（4マス用）減らします。
開口より細いケーブルやコネクタは通り抜ける可能性があります。
印刷時間の短縮と実物の強度は未確認です。

## 差し込み寸法

前後の壁は厚さ3.2mm。その内側に幅2.4mm・深さ2mmの溝を設け、外皮1.2mmを残します。
板厚方向の逃げは片側0.2mm、前後の板端と溝底の逃げも各0.2mmです。
上端まで溝が開いているため、板は上から抜き差しできます。

実物での嵌合は未確認です。印刷条件による差は
[共通モジュール](../../../../modules/gridfinity_cable_holder.scad)の
`gfc_slot_clearance`（板厚方向の総量）と `gfc_end_clearance`（前後の片側）で調整できます。
3マス用と4マス用の仕切り板は長さが異なります。

形状検査はリポジトリのルートで `python3 tests/cable-holder.py` を実行します。
設計の根拠は[設計台帳](../../../../ledger/designs/gridfinity-cable-holder.md)を参照してください。
