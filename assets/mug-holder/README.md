# マグカップホルダー

`mug_holder.scad`は外径83.0mmのマグを受け、クランプへ横向きのM8ネジ1本で
固定するホルダーです。底の六角穴から排水します。

| 箇所                           | 寸法 (mm)                    |
| ------------------------------ | ---------------------------- |
| 収納内径 / 内高さ              | 83.6 / 32.6                  |
| 円筒壁 / 底厚                  | 2 / 2                        |
| 円筒外径 / 全高                | 87.6 / 34.6                  |
| 取付座を含む外形               | 幅87.6 × 奥行97.0 × 高さ34.6 |
| 排水穴 / 桟 / 外周無垢幅       | 六角対辺6 / 2 / 最低3        |
| クランプ板の逃げ               | 幅24.4 × 奥行3.8             |
| 回転止めの左右壁               | 各2                          |
| ネジ通し穴 / 頭の段穴          | Φ8.4 / Φ14.4                 |
| 頭の座面からクランプまでの厚さ | 4.4                          |
| ネジ中心の底面からの高さ       | 24.35                        |

取っ手の下端は32.6mm以上あるため、円筒の上縁に切り欠きは設けません。
取付部はカップの外側へ厚くし、高さ3mmの小トラス頭が収納内径に出ないよう
0.2mm沈めています。頭は円筒形の段穴へ収めます。

## クランプとの位置関係

X/Yの原点はカップ中心、Z=0は印刷底面。+Yがクランプ側です。
クランプ板に接触する面はY=49.4、左右の回転止めがデスクへ接触する面はY=53.2。
板幅24mmに対して左右合計0.4mmのすきまがあります。

**高さ28.1mmはコの字の外高と仮定しています。** 上腕がデスク上に載り、その厚さが
3.8mmなら、ホルダー上端をクランプ上端より3.8mm下げることでデスク面に揃います。
穴中心Zは`34.6 + 3.8 - 28.1/2 = 24.35`です。28.1mmが内高であれば、
`clamp_h`を上下の板厚込みの35.7mmへ変更してください。穴中心はZ=20.55へ追随します。

軸長8mmのうち4.4mmが樹脂座を通り、3.6mmがクランプへ掛かります。
板厚3.8mmに対して先端に0.2mmの逃げを残します。
軸径7.8mm・頭径13.8mmには、印刷用の直径方向すきま0.6mmを加えています。
底厚・排水穴寸法・すきまはSCAD冒頭で調整できます。

## 生成・取付

```sh
mkdir -p dist/mug-holder
openscad --export-format binstl -o dist/mug-holder/mug_holder.stl assets/mug-holder/mug_holder.scad
python3 tests/mug-holder.py
```

底面Z=0を印刷面にします。横向きの丸穴と段穴の天井はスライサーで確認してください。
取付時はマグを外し、ネジをカップの内側から入れて、上から差し込んだ
ネジ頭に合うL字ドライバーで締めます。上腕の下へ上縁を合わせ、板の左右を回転止めの
間へ収めます。実プリント・取付・荷重の確認は未実施です。

依頼原文と判断は[設計台帳](../../ledger/designs/mug-holder.md)にあります。
