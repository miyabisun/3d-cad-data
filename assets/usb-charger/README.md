# LX取付用USB充電器ホルダー

`lx_holder.scad`は、充電ポートを上にしたUSB充電器を受ける一体型ホルダーです。
LX台座の空いている横2穴へM6皿ネジで固定します。

上から充電器を差し込み、底穴から電源プラグを挿します。固定時は充電器を外し、
皿ネジをホルダー内側に入れて、前壁の工具穴から長いビットで締めます。
工具穴は6.35mm六角軸用です。ビットホルダーやチャックを通す寸法ではありません。

前は工具穴側、奥はクランプ側です。充電器の実測時の前面を工具穴側に向けます。
原点は左右中央・収納部の前端・部品底面です。

内寸70.2×31.8mm、収納深さ73.6mm、外寸76.2×38.8×76.6mm。
内側R4、外周の縦の角はR7です。底面と上縁の水平エッジは平らに残しています。

未実測の仮値は、取付穴中心の上端からの距離15mmと、皿穴の対辺12.4mm・深さ3mmです。
SCAD冒頭の`mount_from_top`・`head_flat`・`head_depth`で調整できます。
底穴21×13mmはジャック実測値へ四方2mmを足したものです。
電源プラグの樹脂外装がこの開口を通るかは現物合わせが必要です。

STL生成:

```sh
mkdir -p dist/usb-charger
openscad -o dist/usb-charger/lx_holder.stl assets/usb-charger/lx_holder.scad
```

底面Z=0を下にして配置します。六角穴の天井と皿座付近の印刷状態はスライサーで
確認してください。実機への装着と印刷は未確認です。

形状検査は`python3 tests/usb-charger.py`です。設計の根拠と依頼原文は
[設計台帳](../../ledger/designs/lx-usb-charger-holder.md)にあります。
