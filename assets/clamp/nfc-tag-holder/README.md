# NFCタグ台

`nfc_tag_holder.scad`は、デスクのクランプ天板へM8ボルト1本で留め、
天面にΦ25mmのNFCタグシールを貼る円柱です。ボルトの頭は天面と揃うまで沈むため、
タグはボルト頭ごと平らな天面へ貼れます。タグが傷んだら剥がして貼り替えます。

取得・STL生成の共通手順は[ルートのREADME](../../../README.md)を参照してください。
以下のコマンドはリポジトリのルートで実行します。

| 箇所             | 寸法 (mm)                   |
| ---------------- | --------------------------- |
| 外径 / 高さ      | 28 / 7                      |
| 上下の面取り     | 幅1 × 高さ1の45度直線       |
| 天面の平らな範囲 | Φ26（タグΦ25）              |
| M8通し穴         | Φ8.4、Z0〜4                 |
| 頭の座ぐり       | Φ14.2（頭Φ13.8+0.4）、深さ3 |

高さ7mmは、ボルト軸8mmからクランプ天板4mmを引いた樹脂座4mmと、頭の厚さ3mmの和です。
実測の軸長7.9mmのうち3.9mmが天板へ掛かり、先端は天板の下へ出ません。
天板の回転止めは設けず、平底をボルト1本の締結で押さえます。

## 生成・取付

```sh
mkdir -p dist/clamp/nfc-tag-holder
openscad --export-format binstl -o dist/clamp/nfc-tag-holder/nfc_tag_holder.stl assets/clamp/nfc-tag-holder/nfc_tag_holder.scad
python3 tests/nfc-tag-holder.py
```

底面Z=0を印刷面にします。サポートは不要です。クランプ天板の中央のM8穴へ
上からボルトで留めてから、天面にタグを貼ります。実物の収まりは未確認です。

設計の根拠と変更履歴は[設計台帳](../../../ledger/designs/nfc-tag-holder.md)にあります。
