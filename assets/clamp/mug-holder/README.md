# マグカップホルダー

`mug_holder.scad`は外径83.0mmのマグを受け、クランプへ横向きのM8ネジ1本で
固定するホルダーです。底の六角穴から排水します。
内径85.6mmではボトルがぐらついたため、84.6mmへ1mm縮めました。壁厚は2mmです。

| 箇所                           | 寸法 (mm)                      |
| ------------------------------ | ------------------------------ |
| 収納内径 / 内高さ              | 84.6 / 32.6                    |
| 円筒壁 / 底厚                  | 2 / 3                          |
| 円筒外径 / 全高                | 88.6 / 35.6                    |
| 取付座を含む外形               | 幅88.6 × 奥行98.0 × 高さ35.6   |
| 底と内壁の接続                 | R2                             |
| 上縁                           | 内外周・取付座・回転止めともR1 |
| 底外周                         | 幅0.4 × 高さ0.4の45度面取り    |
| 排水穴 / 桟 / 外周の無垢幅     | 六角対辺6 / 2 / 最低3          |
| クランプ板の逃げ               | 幅24.4 × 奥行3.8               |
| 回転止めの左右壁               | 各2                            |
| ネジ通し穴 / 頭の段穴          | 六角対辺8.4 / 14.2             |
| 頭の座面からクランプまでの厚さ | 4.4                            |
| ネジ中心の底面からの高さ       | 25.35                          |

取っ手の下端は32.6mm以上あるため、円筒の上縁に切り欠きは設けません。
取付部はカップの外側へ厚くし、高さ3mmの小トラス頭が収納内径に出ないよう
0.2mm沈めています。軸と頭の穴は上下に平らな辺を置いた六角形です。
斜辺から水平な天井のブリッジへ繋がり、天井幅は軸穴約4.85mm、頭穴約8.20mmです。

取付座と回転止めの縦の角もR1で丸め、上縁へ連続させています。
底外周の面取りは45度の直線で、下向きの球面はありません。上縁のR1は
上に行くほど材料を減らす形です。ハニカム穴は底厚3mmを真っ直ぐ貫通します。
内底R2により、底の平らな範囲の直径は80.6mmとなります。マグの底の角が
丸くない場合、底平面より高い位置でRに当たります。今回の縮径後の底形状との実物合わせは未確認です。

## クランプとの位置関係

X/Yの原点はカップ中心、Z=0は印刷底面。+Yがクランプ側です。
クランプ板に接触する面はY=49.9、左右の回転止めがデスクへ接触する面はY=53.7。
板幅24mmに対して左右合計0.4mmのすきまがあります。

**高さ28.1mmはコの字の外高と仮定しています。** 上腕がデスク上に載り、その厚さが
3.8mmなら、ホルダー上端をクランプ上端より3.8mm下げることでデスク面に揃います。
この計算による机との面一は、内径83.6mm版の実使用で確認済みです。
穴中心Zは`35.6 + 3.8 - 28.1/2 = 25.35`です。28.1mmが内高であれば、
`clamp_h`を上下の板厚込みの35.7mmへ変更してください。穴中心はZ=21.55へ追随します。

軸長8mmのうち4.4mmが樹脂座を通り、3.6mmがクランプへ掛かります。
板厚3.8mmに対して先端に0.2mmの逃げを残します。
軸の六角対辺は指定の8.4mm。頭径13.8mmには対辺方向の総すきま0.4mmを加えています。
底厚・排水穴寸法・すきま・丸みはSCAD冒頭で調整できます。

## 生成・取付

円柱を先に面取りし、別に面取りした取付座・回転止めの四角柱を結合してから、
収納部・ネジ穴・排水穴をくり抜きます。

```sh
mkdir -p dist/clamp/mug-holder
openscad --export-format binstl -o dist/clamp/mug-holder/mug_holder.stl assets/clamp/mug-holder/mug_holder.scad
python3 tests/mug-holder.py
```

底面Z=0を印刷面にします。取付時はマグを外し、ネジをカップの内側から入れて、
上から差し込んだネジ頭に合うL字ドライバーで締めます。上腕の下へ上縁を合わせ、
板の左右を回転止めの間へ収めます。内径83.6mm版は1日の実使用で印刷成功・ネジの収まり・
回転止め・机との面一を確認済みです。今回の縮径版の収まりは、次回の印刷で確認します。

依頼原文と判断は[設計台帳](../../../ledger/designs/mug-holder.md)にあります。
