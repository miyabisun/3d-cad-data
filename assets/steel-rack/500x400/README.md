# steel-rack / 500x400

500x400mm スチールラック用のパーツ群。

## corner_bracket_large.scad

L字コーナーブラケット（大）。天板接続プレート付き。

- 2本の `long_bar` (147mm) をL字に組み合わせ
- 30x30x6mm の接続プレートを追加し、M4 ボルト穴 + ナットトラップで天板を固定
- 内側コーナー: R4 フィレット
- プレート外側コーナー: R8 フィレット

## corner_bracket_small.scad

L字コーナーブラケット（小）。片側が短い非対称形状。

- `long_bar` (147mm) + `short_bar` (25mm) のL字
- 短辺側は6mm分カットして壁面への干渉を回避
- 内側コーナー: R4 フィレット（3mmオフセット）

## bolt_spacer.scad

ボルトスペーサー。2つのボルト穴の間を繋ぐ小型パーツ。

- 2つの円を hull で繋いだ形状（穴中心間距離: 12.7mm）
- 片側にボルト貫通穴（6.6mm径）を配置し、穴の中心線でカット
- -Y側の底面に 45度フレアの滑り止めを追加（高さ0.5mm、幅制約 |x| <= 3.3mm）

## separator.scad

ワッシャー状のセパレーター。ボルトに通してフレーム間のスペースを確保する。

- 外径 20mm / 高さ 3.5mm / 穴径 4.6mm

## slide_rail_outer_front.scad / slide_rail_outer_rear.scad

スライドレール外側とL字アングルを接合するL字ブラケット（手前用・奥用）。
共通形状は `modules/slide_rail_outer_bracket.scad`。設計の経緯と確定値は
`ledger/designs/steel-rack-500x400.md` を参照。

- 高さ45mm（レール断面と一致）・短辺厚10mm・長辺厚8mm・内側R4フィレット。
  組付け実測でレール間隔が385mmしかなくケース412mmが入らないため、
  レール接触面を片側14mm（(412−385)/2 + 0.5）ラック外側へ移した断面。
  L字アングルのM6実穴を再利用するためM6中心と部品外端の絶対位置は不変で、
  長辺を2mm削って（10→8）M6ナット挿入口の内縁と長辺外面をツライチにした
- 六角穴はすべて上下の辺が水平（flat-up）で、天井は短い水平ブリッジになる
  （対角上下だと天井面が水平から30°になり垂れる — 印刷試験で確認済み）。
  クリアランスは呼び寸法+0.4mm
- 短辺: M6の2段六角穴×2（通し側 二面幅6.4mm×5mm → ナット窪み
  二面幅10.4mm×5mm、高さ22.5±12mm）。ナット窪みは+X側へ延長した
  挿入回廊になっており、経路に掛かるフィレットを局所カットして
  M6ナットを横から真っ直ぐ挿入できる（長辺外面には0.2mmの逃げ溝）
- 長辺: M4小トラスネジ用（高さ22.5mm）。通しの二面幅4.4mm六角を全厚に
  貫通し、L字の内側面から深さ2.8mm・二面幅7.4mmのM4ナット窪み。ネジは
  レール内側から刺さり（トラス頭はスライダーと干渉しない実測済み）、
  ナットが窪みの底で受けてレール板と共締めする。旧・木ネジのセルフタップ
  方式は緩み・積層割れのため廃止（φ14ガードも不要になり削除）
- datum: X=0が自分側のL字アングル外側面。M4位置は手前用 37/101.5mm、
  奥用 79.5/176mm（どちらも実プリントで判明したズレを、各穴を自datumから
  遠ざかる方向へ+3/+3.5mm補正済み）
- M6が高さ対称のため上下反転で左右のレールに共用できる（ミラー印刷不要）
- 印刷向き: L断面をビルドプレートへ寝かせる（層と平行に荷重を受ける）

## slide_rail_inner_support.scad / slide_rail_inner_rear_l.scad / slide_rail_inner_rear_r.scad

スライドレール内側とオープンフレームケースを接合する支持部品（対称型・
奥用左・奥用右）。共通形状は `modules/slide_rail_inner_block.scad`。
設計の経緯と確定値は `ledger/designs/steel-rack-500x400.md` を参照。

- ネジ穴ブロック 42×**10**×14mm（X=レール方向・Y=レール接触面からラック中央
  向き・Z=ブロック底面が0）。レール(内)は高さ24.4mmでそのド真ん中12.2mmに
  横穴が並ぶため、ブロックは穴中心（部品z=7）で取り付き、下端はレール下端
  から約5.2mm浮く。奥行きが10mmなのは**M4×10**がケース側から通し7.2mm +
  窪み2.8mmでナットへ全掛かりするため（旧14mmは対応する長さのM4ネジが無く
  ナットに届かなかった。実物確認で superseded）
- M4小トラスネジ穴×2（X=±14mm・間隔28mm・Z=7mm、軸はY）。二面幅4.4mmの
  通し六角が全厚を貫通し、**ケース側の面（y=10）**に二面幅7.4mm・深さ2.8mmの
  ナット窪みが開く。ボルトは**レールの向こう側から**レール壁と土台を貫通し、
  窪みのナットとで「頭｜レール壁｜土台｜ナット」を挟んで締め上げる（旧・
  レール接触面側の窪みはボルトとナットが土台の肉だけを締める自己締結で、
  レールを挟めない誤り。2026-08-16の実物指摘で superseded）。窪みの六角は
  y=7.2mmから**2.8 + 24 = 26.8mm**押し出してあり、柱を貫通する**六角トンネル**に
  なる（柱の側面には「＜」形の切り欠きとして現れ、ナットの逃げになる）。
  六角はすべて上下の辺が水平（flat-up）で、寸法は外側ブラケットと同じ
  クリアランス基準
- スタンドオフ **24×24mm**・上端 z=34mm（ブロック14 + 上へ20mm突出）。レール
  接触面から2mm離して立てる（`standoff_setback`。Y 2..26mm）ため、ブロックの
  背面（y=10）より16mmケース側へ張り出す。**下端は z=7mm**（`column_z0` = M4軸の
  高さ）で、地面から7mmまでは柱を削り落としてある（旧10×10はケース四隅の
  ネジ穴に落ち込んで支持にならず superseded／z=0まで下ろした足痩せ形状は
  プリントできず superseded。どちらも2026-08-16の実物フィードバック）。
  柱は土台と z 7..14mm で重なって接合し、この6箇所がケースを浮かせて
  四隅の穴を跨いで受ける
- **垂直エッジのみ R2**（`corner_r`）。角柱の角が刺さって痛いための面取りで、
  柱は四隅とも、土台は**ナット側（y=0）の2隅だけ**落とす（ケース側の隅は柱と
  繋がる面なので直角のまま）。**上下の水平エッジは未加工** — 3Dの minkowski
  ではなく2D輪郭を `linear_extrude` して垂直エッジだけ丸めている（水平エッジの
  面取りはプリント難度が飛躍的に上がるため）
- **使い分けは 4 + 1 + 1 の物理6個**:
  - `slide_rail_inner_support.scad`: 柱がブロック中心（偏心0）で X 鏡像不変。
    手前L/R・中央L/R の**4個**をこの1設計で印刷して使い回す（ミラー印刷不要）
  - `slide_rail_inner_rear_l.scad` / `slide_rail_inner_rear_r.scad`: 奥用は
    柱をラック手前側へ21mm寄せるため X 対称性が破れ、左右が真の鏡像対に
    なる（右は左の `mirror([1,0,0])`）。**各1個**
- 左右の規約: 「左」「右」はラック手前から見た向き。部品ローカルの +X は
  ラック手前方向（奥用の datum はレール奥端から32mm = 奥ペアの中点）
- 柱の位置: ケース端（レール端から39mm）から2mm奥まった41mmに柱のケース側の
  面が来る。奥用の偏心は 39 + 2 + 12 − 32 = **21mm**（旧 +14 は柱10×10 の
  導出で superseded）。手前位置は偏心0のままで、柱24×24 はレール端から
  34..58mmを占めてケース前端より5mmはみ出すが、柱上面はケース底より下で
  残り19mmがケース下へ入るため許容（user合意）
- `standoff_inset`（2mm・X方向）は**現物合わせ**前提のパラメータで、奥用 entry が
  偏心の導出に使う。組んでみてスカスカ・ガタつくようなら詰める
- `standoff_setback`（2mm・Y方向）も**現物合わせ**前提。実物へ当てたところ
  柱をスライドレールから多少離す必要が判明したための暫定値。柱が土台より
  大きくなったため旧「柱が土台に収まる」上限4mmは廃止し、代わりに土台と柱の
  重なりがフィレット2つ分より広いこと（X・Y とも `>= 2 * corner_r`）を assert
  で守る。Y の重なりは `block_depth − standoff_setback` なので、現行値
  （土台奥行10・`corner_r` 2）での実質上限は **6mm**
- 印刷向き: ブロック底面をビルドプレートへ置く（M4軸が水平になり、六角穴は
  自然に flat-up。柱もブロックと同じ z=0 から立ち上がって接地する）

## drilling_guide.scad

フレームへの穴あけ位置決めガイド。

- フレーム端にかぶせて使う段差構造（リップ: 5mm）
- 底面プレート厚 4mm + ドリルガイド穴深さ 10mm
- 角に R4 フィレット
- デフォルト: エッジから 17.5mm の位置に 4.2mm 穴
